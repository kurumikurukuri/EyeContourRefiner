# EXP009: small_eye_filter sweep

## 目的

eye_scale（目の点群バウンディングボックス対角長）が下位 20% の目を
manifest から除外したデータセットで学習し、フィルタリングの効果を検証する。

**仮説**: 極端に小さい目は解像度が低く、アイライン境界の視認が困難なため
アノテーション精度が低下しやすい。これらを除外することで、モデルの学習安定性と
holdout 精度が向上する可能性がある。

## フィルタリング方針

- **閾値**: 訓練データの eye_scale ユニーク値（眼単位）の 20 パーセンタイル
- **適用対象**: train / holdout 両方に同じ閾値を適用
- **除外単位**: 眼単位（同一 image_path + part_name の全アノテーション点を一括除外）

```
eye_scale = 同一眼の全 P/Q 点群のバウンディングボックス対角長 [px]
閾値      = percentile(train eye_scale ユニーク値, 20)
除外条件  = eye_scale < 閾値
```

## 条件

| 条件 | ベースライン | norm_eye_scale | patch範囲 |
|---|---|---|---|
| K1_H1 | EXP006 H1_baseline | なし | -0.5〜1.5 |
| K2_H2 | EXP006 H2_wide_patch | なし | -1.0〜2.0 |

manifests: EXP006 の manifests をフィルタリングして `EXP009/manifests/` に保存

## データ統計

| | EXP006 (元) | EXP009 (フィルタ後) | 除外数 |
|---|---|---|---|
| train samples | 4,718 | 3,836 | 882 (18.7%) |
| test samples  | 1,022 | 868  | 154 (15.1%) |

小さい目の true_t_raw の特性: mean=0.701, std=0.266（通常分布と差なし）

## 考察

### 1. small_eye_filter の効果：なし（むしろ有害）

共通サンプル（868点）での公平比較では、小眼フィルタリングを行った K1・K2 はいずれも
EXP006 の対応条件より **MAE が悪化** した。

- K1 vs H1: +0.003 悪化
- K2 vs H2: +0.009 **大幅悪化**

小さい目を取り除くことで学習データが減少し、汎化性能が低下したと考えられる。
フィルタリングによる「ノイズ除去効果」よりも「データ量減少の悪影響」が上回った。

### 2. H2 の wide_patch 優位性がほぼ消失

EXP006 では H2（wide_patch）が H1（baseline）より +4.5% 向上していた（生t MAE: 0.1267 vs 0.1325）。
しかし EXP009 では K1・K2 ともにほぼ同等（0.131 vs 0.131）となり、
**wide_patch の優位性がフィルタリングによって失われた**。

これは、wide_patch が特に t の大きい（アイライン末端）サンプルで有効なところ、
そうした難しいサンプル群（小さい目）を取り除いたことで差が消えたと解釈できる。

### 3. 平均回帰バイアスは改善せず

t < 0.2 での過大予測（+0.39〜0.42）および t > 1.0 での過小予測（-0.31〜-0.36）は
全条件で一貫して存在し、フィルタリングでは解消されない。
これはモデルアーキテクチャやロス関数の問題であり、データの質的な問題ではない可能性が高い。

### 4. 小眼サンプルのMAEは高いが、それは除外すべき理由にならない

除外された小眼サンプル（154点）の MAE は H1で 0.161、H2で 0.153 と高めだったが、
true_t の分布（mean=0.701, std=0.266）は通常サンプルと変わらない。
アノテーション精度が特別低いのではなく、単に難しいサンプルである。

## 結論

**small_eye_filter（下位20%除外）は有効ではない。採用しない。**

- 共通サンプルでの性能は悪化
- wide_patch の優位性が消失
- 平均回帰バイアスは改善なし
- EXP006 H2_wide_patch が引き続きベストモデル

次の実験方向として推奨：
- 平均回帰バイアス解消（t分布の不均衡補正、端点専用ロス）
- データ拡張の強化
