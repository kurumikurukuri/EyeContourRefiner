# EXP033: 現行dual標準の seed 間ばらつき測定（3 seed）

## 目的・仮説

EXP029〜EXP032 はすべて 1 seed 学習で、全体・t帯別の有意差が真の効果か run-to-run 分散かを
切り分けられないことが繰り返し課題として挙がっていた（EXP031 では「帯別主張は 2 run 再現を要件化」、
EXP032 では「SB_eyescale の t>=1.2 優位は複数 seed でないと切り分け不能」）。

本実験は現行dual標準（EXP031 SD0_baseline と同一構成）を seed だけ変えて 3 回学習し、
**seed 以外が完全に同一な 2 モデルの間に、どれだけの差・どれだけの「有意差」が出るか**を測る。
これを、今後の 1 seed 比較で「差」とみなすべき最小幅（ノイズフロア）として使う。

**仮説**: 全体 MAE の seed 間差は過去の採用判断で使われた改善幅（〜1%）より十分小さい。
一方、n が小さい極端帯（t<0: n=129、t>=1.2: n=87）では seed だけで大きく揺れる。

## 実験設計・条件

- **実験ディレクトリ**: `experiments/EXP033_seed_variance`
- **config 数**: 3
- **config 一覧**: dual_s42, dual_s43, dual_s44
- **評価指標**: cv_mae, holdout_mae(raw t), passrate(std/strict)
- **passrate 閾値**: std=0.01788 (p10), strict=0.01604 (p5)
- **検定方法**: scipy paired t-test（per-sample abs error）

**変動軸**: `seed` のみ（42 / 43 / 44）。seed は fold 分割・重み初期化・augmentation の乱数列すべてに効く。

**固定条件**: EXP031 SD0_baseline と完全に同一（dual-branch independent、branch B=eye_scale、t_l1、
sigmoid、bc32_pw8、conv4、dropout 0.3、lr 1e-3、wd 1e-4、epochs 200 / patience 50、k=3、batch 32、
aug_flags=63、aug_prob 1.0、endpoint_blend 0.25、is_upper あり）。manifest も EXP031 の db_replica 固定
テストセットをそのままコピー（train 16,548 行 / test 4,900 行）。

**環境**: `restore_dataset.py --exp 31` で復元した samples.db・画像（1039 枚、取得失敗 0）、
PyTorch 2.11.0+cu128、RTX 3060、num_workers=0。復元 DB で EXP031 SD0 の予測を再評価すると
pass_std=89.04% で元 summary と一致し、DB 復元による評価のずれは無い。

**比較対象（読み取り専用参照）**: `experiments/EXP031_source_space_aug/outputs/SD0_baseline/test_predictions.csv`
（同一構成・同一 seed=42 の過去 run。再現性チェックに使用）。集計は `scr/seed_variance_exp033.py`。

**経緯**: dual_s43 は 1 回目の学習を fold 3 途中で中断し、出力を削除して最初から学習し直した。
本サマリーの dual_s43 はすべてやり直し後の値。

### 全体の解釈

- **全体 MAE の seed 間差は小さい**: range 0.52%、sd 0.27%。全体の paired t-test は 3 ペアとも n.s.
  （p=0.28〜0.85）。全体 MAE・pass_std の 1 seed 比較は、差が約 0.5%（pass_std 約 0.4pt）を超えて
  初めて seed ノイズの外に出る。
- **仮説の前半は支持された**: 過去の採用判断の全体差のうち、EXP027 fcp_p8（−1.03%、p=0.019）は
  seed range の約 2 倍、EXP032 の単独ブランチ vs dual（pass_std −1.1〜−1.2pt、p<0.001）は seed range
  （0.43pt）の約 3 倍で、seed ノイズだけでは説明しにくい。ただし seed は 3 つしかなく、range の
  推定自体が粗い点に注意。
- **seed アンサンブルが seed 間差より大きく効く**: 単体間の差（≤0.52%）より、平均化による改善
  （1.2〜1.7%）の方が大きい。1 モデル内の誤差の一部は seed 依存のばらつきで、平均で打ち消せる。

## t帯別結果考察

- **t<0 帯は seed だけで ±10% 揺れる**: mae の相対 range 10.3%、pass_std は 62.0〜69.0%（7pt 幅）。
  n=129 と小さく、誤差の絶対値も大きい（MAE≈0.29）ため、1 run の値はほぼ信頼できない。
- **0.3-0.7 帯（n=1684）も 4.2% 揺れる**: n が大きいので p 値は極めて小さく出る（s44 vs s42 で
  p=1e-6）が、seed を変えただけの差である。**n が大きい帯ほど「小さなノイズ差」でも p が小さくなる**。
- **0.7-1.0 帯（n=2430）だけは安定**（range 0.5%、全ペア n.s.）。
- **帯間のトレードオフは seed だけで生じる**: dual_s42 は 0.3-0.7 が最良で t<0 が最悪、dual_s43・s44
  はその逆。全体 MAE がほぼ同じでも、帯の間で誤差が入れ替わる。過去の実験で「多数派帯は改善、
  極端帯は悪化」と報告されたパターン（EXP022・EXP028・EXP030）は、seed だけでも同じ形で現れる。

## ペア比較考察

### dual_s44 vs dual_s43

全体 −0.52%（p=0.281, n.s.）、全帯 n.s.。

### 帯別「有意差」の出現頻度

| 比較 | 全体 | 有意な帯 |
|---|---|---|
| dual_s43 vs dual_s42 | n.s. | t<0 (***)・0.3-0.7 (***) |
| dual_s44 vs dual_s42 | n.s. | t<0 (**)・0.3-0.7 (***)・1.0-1.2 (*) |
| dual_s44 vs dual_s43 | n.s. | なし |
| dual_s42 vs EXP031 SD0（同一 seed） | n.s. | t<0 (***)・0.3-0.7 (**) |

**同一構成どうしの 4 比較のうち 3 比較で、帯別に p<0.01 の差が出た**。paired t-test は
「同じテストサンプル上の 2 つの予測の差」を検定するもので、「学習を繰り返したときのばらつき」は
考慮していない。そのため、モデル間の帯別有意差は seed 由来の差でも容易に出る。

**過去実験への影響**:
- EXP022 で bc32_pw8 を採用した根拠（全体 n.s.、t<0 p=0.029・0-0.3 p=0.0075 改善、0.3-0.7 p=0.0027
  悪化）は、本実験で seed だけで出た差と同じ形・同程度の p 値で、**seed ノイズと区別できない**。
- EXP030 AF2（全体 n.s.、多数派帯改善・極端帯悪化）、EXP028 sigma=0.01（全体 n.s.、t<0 改善・
  t>=1.0 悪化）の帯別トレードオフも同様に、seed ノイズの範囲内の可能性が高い。
- EXP032 SB_eyescale の t>=1.2 優位（+24.31%）は、t>=1.2 の seed range（2.5%）を大きく超えるため、
  seed ノイズだけでは説明しにくい（ただし n=87）。
- EXP031 が導入した「帯別主張は独立 2 run で符号が一致し、両方で有意」の要件は妥当だった。

## 結論

**現行dual標準の 1 seed 評価は、全体 MAE では安定しているが、t帯別では信頼できない。**

- 全体 MAE の seed 間 range は 0.52%（sd 0.27%）、pass_std の range は 0.43pt。1 seed 比較で
  全体の改善を主張するには、この幅を明確に超えることを目安にする。
- t帯別の有意差は seed を変えただけ（さらには同じ seed の再学習だけ）で p<0.001 レベルで出る。
  **1 seed の帯別 paired t-test を採用根拠にしてはならない**。特に t<0（±10%）、0.3-0.7・1.0-1.2
  （±4%）は揺れが大きい。0.7-1.0 帯だけは安定している。
- 現行ベストの値は「0.0845 ± 0.0002（3 seed mean ± sd）、pass_std 88.8 ± 0.2%」と表記するのが正確。
  EXP031 SD0 の 0.084326 / 89.04% は、この分布の良い側の 1 サンプルだった。
- 副次成果: **3 seed アンサンブルで MAE −1.4%（0.083285、pass_std 89.16%）**。全単体 seed に対し
  p<1e-4 で有意。精度だけを見ればこれが現時点の最良だが、推論コストは 3 倍。

## 今後の課題

- **評価ルールの改訂**: 今後の比較実験は baseline・候補とも複数 seed（最低 3）で学習し、
  seed 平均の差を seed 間 sd と比べて判定する（例: seed をブロックとした検定、または
  seed ごとの差の符号一致）。帯別主張は全 seed で符号一致を要件とする。
- **過去の 1 seed 帯別根拠で採用した構成の再検証**: 特に EXP022 の bc32_pw8 採用（vs bc32_pw32）を
  複数 seed で再比較する。
- **EXP027 perspective aug の再検証**: 全体 −1.03% は seed range の約 2 倍。db_replica で
  複数 seed 比較すれば、本当に効くかを判断できる（学習時間は約 8 倍）。
- **seed アンサンブル vs fold 数増加**: 9 モデル平均の効果が「seed の多様性」によるのか「モデル数」
  によるのかを、k=9 や 1 seed 内の多モデル平均と比べて切り分ける。face_makeup への配布サイズ・
  推論時間とのトレードオフ評価も必要。
- 3 seed では sd・range の推定が粗い。ノイズフロアを確定させるには 5 seed 程度が望ましい。
- 非決定性の要因（cuDNN の非決定的アルゴリズム）を `torch.use_deterministic_algorithms` で
  潰した場合に、同一 seed で完全再現できるかは未検証。
