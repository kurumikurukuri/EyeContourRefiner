# EXP018: pq_ratio 困難サンプル対策 & アーキテクチャ強化 sweep

## 目的・仮説

- **目的**: EXP017 で改善されなかった pq_ratio < 0.10 サブグループの MAE を、pq_ratio-based 手法とアーキテクチャ強化の両面から改善する。
- **仮説**: (X) pq_ratio weighted sampler / loss 重み付けで小 pq サンプルの学習を強化すれば、pq<0.10 の MAE が改善する。(Y) より深い CNN または補助特徴量（顔形状）の導入でモデル表現力を高めれば、全体 MAE も改善する。
- **マニフェスト**: `split_holdout.py --exp 018`（seed=42, ratio=0.2）で生成。train: 13,650件、test: 3,262件（EXP017 と同規模、分割は再生成）。

## 実験設計・条件

**ベース設定（EXP017 W0_baseline 引き継ぎ）**: backbone=custom / loss=t / use_sigmoid=true / use_batchnorm=true /
num_conv_layers=4 / dropout=0.3 / lr=1e-3 / wd=1e-4 / epochs=200 / batch=32 / k=3 / patience=50 / seed=42 /
aug_flags=127 / patch_t_min=-2.0 / patch_t_max=3.0 / patch_perp_scale=2.0 / patch_h=64 / patch_w=64 /
label_t_min=-1 / label_t_max=2 / num_workers=4

| グループ | 条件 | 変更点 | 目的 |
|---------|------|--------|------|
| X (pq対策) | X0_baseline | なし（参照基準） | — |
| | X1_pq_sampler_a3 | pq WeightedRandomSampler α=3, threshold=0.10 | 小 pq の過剰サンプリング（中） |
| | X2_pq_sampler_a5 | pq WeightedRandomSampler α=5, threshold=0.10 | 小 pq の過剰サンプリング（強） |
| | X3_pq_loss_weighted | loss_fn=pq_weighted α=3, threshold=0.10 | 小 pq の損失重み付け |
| Y (アーキ) | Y1_custom_conv5_d4 | conv5層・dropout=0.4 | CNN 深層化・正則化強化 |
| | Y2_aux_face_shape | 補助顔形状特徴量 11次元 concat, use_is_upper=false | グローバル顔情報の活用 |

## 考察

### 1. 仮説は棄却：pq_ratio-based 戦略は pq<0.10 の MAE を改善しない

pq_weighted_sampler（X1, X2）および pq_loss_weighted（X3）はいずれも pq<0.10 サブグループの MAE を有意に改善しなかった。

| 手法 | pq<0.10 MAE | vs X0 | 全体 MAE コスト |
|------|:-----------:|:-----:|:---------------:|
| X1 sampler α=3 | 0.1088 | +0.0004 | +0.0004 |
| X2 sampler α=5 | 0.1099 | +0.0015 | +0.0019 |
| X3 loss weighted | 0.1094 | +0.0010 | +0.0005 |

すべての pq_ratio-based 手法が pq<0.10 サブグループで baseline より悪化している。過剰サンプリングは全体 MAE を悪化させるのみで、loss 重み付けも効果がない。

**理由の推察**: pq_ratio < 0.10 のサンプル（目が小さい / PQ が短い）は、パッチ画像自体の情報量が少なく、同じ画像を何度見せてもモデルが抽出できる特徴に限界がある。サンプリング量の問題ではなく、入力パッチの情報量の問題である可能性が高い。

### 2. Y1 conv5+d4 は t 極端値で最良だが全体優位とは言えない

Y1_custom_conv5_d4 は t<0（0.3645, −6.6%）と t>1.2（0.2333, −2.2%）の両方で最良を記録した。conv 層の深化（4→5）と dropout 強化（0.3→0.4）が、t 極端値のような難しいサンプルでの過学習抑制に寄与した可能性がある。

しかし CV MAE（0.03145, 最良）に対し Holdout MAE（0.03003, baseline より悪化）と乖離があり、汎化性能の真の改善は確認できない。また端点（0.1176, 最悪）・pq<0.10（0.1107, 最悪）では劣る。

### 3. 補助顔形状特徴量（Y2）は baseline と有意差なし

Y2_aux_face_shape は全体 MAE 0.0905（X0 比 +0.3%、paired t-test **p=0.65**）・Holdout MAE 0.03006（+0.3%）で、baseline との差は検出できない。サブグループ別では端点 0.1149（−0.7%、X1 と並んで最良）、pq<0.10 0.1085（+0.1%）、t>1.2 0.2349（−1.6%）、t<0 0.4052（+3.8%）。

t<0 は n=35、t>1.2 は n=51 しかなく、この標本数で数 % の差を解釈する根拠はない。**Y2 の結論は「全指標で baseline と同等」**である。

差が出ない理由は、投入した aux 11 次元の内訳から説明できる。

| 成分 | 次元 | 実際に運んでいる情報 |
|---|---:|---|
| face_yaw/pitch/roll の sin/cos | 6 | 顔全体の向き。同一眼のどの点でも同じ値 |
| pq_angle_cos/sin | 2 | PQ ベクトルの向き |
| position_polar_cos/sin | 2 | 点番号の符号化。`point_index` と `is_upper` から一意に決まる |
| is_upper | 1 | `use_is_upper=false` にした分をここへ移しただけ |

11 次元のうち **モデルにとって新規なのは顔姿勢 6 次元と PQ 角度 2 次元だけ**で、残り 3 次元は点番号と上下の符号化にすぎない。顔姿勢 6 次元は眼単位で定数なので、点ごとの t を分ける情報を持たない。パッチ内の局所判断に対しては「そのサンプルが属する顔グループ」を示すだけの弱い信号であり、baseline と有意差なしという結果はこの構成と整合する。



### 4. X1 pq_sampler_a3 は t<0 で第2位の改善

X1（α=3）は t<0 で −3.4% 改善（0.3903→0.3771）し、全体 MAE の悪化も X0 比 +0.4% と最小限。X2（α=5）は過剰サンプリングが強すぎて全指標で悪化。pq sampler を使うなら α=3 程度が上限。

### 5. EXP017 との比較

| | EXP017 W0 | EXP018 X0 (今回) |
|---|:---:|:---:|
| CV MAE | 0.03177 | 0.03202 |
| Holdout MAE | 0.02991 | 0.02997 |

同一設定の baseline 同士でほぼ同等（差 < 0.1%）。マニフェスト再生成と訓練再実行の変動範囲内。

### 6. pq<0.10 が改善しない根本原因

EXP016〜018 を通じて一貫している: **pq_ratio < 0.10 のサンプルは、サンプリング戦略・損失重み・アーキテクチャ強化のいずれでも改善しない**。

考えられる根本原因:
- **入力パッチの物理的限界**: PQ が短い（目が小さい）画像では、パッチ内のアイライン情報そのものが乏しい
- **アノテーション精度**: 小さい目では t の正確な判定が難しく、ラベルノイズが多い可能性
- **データ量不足**: pq<0.10 は約 43% を占めるが、その中でも極端に小さいサンプルは少数

## まとめ

- **全体 MAE は全条件が baseline と同等**: 最良の X0_baseline（0.0902）と最悪の X2（0.0921）の差でも 2.1%
- **pq_ratio 対策は全て無効**: sampler も loss 重みも pq<0.10 を改善せず、全体を悪化させるのみ（X1 のみ t<0 −3.4%）
- **Y1 conv5+d4 は t 極端値で有効**: t<0 −6.6%, t>1.2 −2.2% 改善。ただし端点・pq<0.10 は悪化
- **Y2 補助特徴量は baseline と有意差なし**: 全体 +0.3%（paired t-test p=0.65）。端点のみ −0.7% で X1 と並ぶ最良だが、t 極端値の差は n=35 / n=51 では判定できない
- **Y2 の aux はグローバル情報しか運んでいない**: 11 次元のうち新規情報は顔姿勢 6 + PQ 角度 2 のみで、いずれも眼単位で定数のため点ごとの t を分けられない。目形状を表す特徴量は未投入
- **pq<0.10 の根本改善にはパッチ生成の見直しが必要**: 入力レベルの情報量不足がボトルネック

## 次 EXP への示唆

1. **パッチ生成の再設計**: pq_ratio が小さい（目が小さい）サンプルでは、現在の 64×64 パッチでは解像度不足の可能性。perp_scale やパッチサイズを pq_ratio に応じて適応的に調整する手法を検討する。

2. **conv5+d4 の再現性検証**: Y1 の t 極端値改善が訓練実行間で一貫するか、複数 seed で検証する。

3. **補助特徴量の再設計**: Y2 の 11 次元はすべて眼単位で定数か点番号の符号化であり、点ごとの t を分ける情報を持たない。目形状（bbox アスペクト比など）を含む「眼ごとに変わる特徴量」を新規に投入したうえで、各成分の寄与を個別に評価する。

4. **データ品質の改善**: pq<0.10 サンプルのアノテーション精度を確認し、ラベルノイズが MAE 下限を引き上げている可能性を排除する。
