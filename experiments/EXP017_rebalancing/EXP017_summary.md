# EXP017: データ再バランス sweep（mid-t 削減 × t 極端値 weighted sampler）

## 目的・仮説

- **目的**: 易しいサンプル（0.5 < t < 0.9、全体の約65%）を削減し、困難サンプル（t 極端値・小 pq_ratio）に学習を集中させたとき、全体 MAE およびサブグループ MAE がどう変わるかを検証する。
- **仮説**: mid-t 削減と t 極端値 weighted sampler を組み合わせることで、全体 MAE を維持しつつ困難サブグループの MAE を改善できる。
- **新規マニフェスト**: `split_holdout.py --exp 017`（seed=42, ratio=0.2）で生成。train: 13,650件、test: 3,262件。

## 実験設計・条件

**ベース設定（EXP016 S12 引き継ぎ）**: backbone=custom / loss=t / use_sigmoid=true / use_batchnorm=true /
num_conv_layers=4 / dropout=0.3 / lr=1e-3 / wd=1e-4 / epochs=200 / batch=32 / k=3 / patience=50 / seed=42 /
aug_flags=127 / patch_t_min=-2.0 / patch_t_max=3.0 / patch_perp_scale=2.0 / patch_h=64 / patch_w=64 /
label_t_min=-1 / label_t_max=2

|------|----------------:|---------------:|------|
| W0_baseline | 1.0 | — | 参照基準（変更なし） |

## 考察

### 1. 仮説は棄却：mid-t 削減は全体 MAE を悪化させる

holdout_mae の全条件が W0_baseline（0.029906）を下回れなかった。特に mid-t 削減条件（W3〜W5）は訓練サンプル数の減少に伴い全体 MAE が +1.5〜+2.5% 悪化した。

易しいサンプルを削除すると、モデルが t ∈ [0.5, 0.9] 域の精度を失い、その損失がサブグループ改善分を上回る。

### 2. t 極端値への効果：trade-off が明確

| セグメント | 最良条件 | W0 比改善 | 全体 MAE コスト |
|-----------|---------|----------|----------------|
| **t < 0** | W5_mid50_tw3: 0.3330 | **−12.7%** | +5.1% |
| **t > 1.2** | W4_mid30: 0.1956 | **−20.5%** | +8.2% |
| pq < 0.10 | W1_tw_a3: 0.1087 | −0.5%（誤差範囲） | +0.2% |
| 端点 | W0_baseline: 0.1148 | — | — |

- **t < 0** の改善には「mid-t 削減 ＋ t_weighted」の組み合わせ（W5）が最も効果的（−12.7%）
- **t > 1.2** の改善には mid-t 削減（W4）が最も効果的（−20.5%）
- **pq_ratio < 0.10** はいずれの戦略でも改善されなかった（サンプリング以外の対策が必要）

### 3. t weighted sampler 単独（W1/W2）の評価

- 全体 MAE への影響は軽微（+0.06〜+0.31%）
- t<0 に対し W2（α=5）で −7.7% の改善
- t>1.2 に対し W1（α=3）で −10.3% の改善
- **コストが少なく一定の極端値改善が得られる**点で、全体 MAE を重視する場合の次善策になりうる

### 4. pq_ratio < 0.10 が改善しない理由

pq_ratio < 0.10 のサンプルは「PQ が短い」ことが困難の原因であり、t 分布の偏りとは独立している。t-based のサンプリング操作では pq_ratio 小サンプルへの効果が薄い。改善には pq_ratio-based の weighted sampler または patch 生成の改善が必要。

### 5. EXP016 との比較

W0_baseline（新マニフェスト）の Test MAE: 0.0900 は EXP016 S12（0.090859）とほぼ同等。新マニフェストの train 件数は 13,650（+770件）で微改善している。

## まとめ

- **全体 MAE の改善には mid-t 削減・weighted sampler は無効**。W0_baseline（フルデータ）が最良。
- **困難セグメントの改善には明確な trade-off がある**: t 極端値を改善するには全体 MAE を +5〜8% 犠牲にする必要がある。
- **ユースケースによる判断**:
  - 全体 MAE 最優先 → W0_baseline（現状路線）
  - t 極端値改善を許容コスト内で進めたい → W1_tw_a3（全体 +0.2%、t>1.2 −10%）

## 次 EXP への示唆

1. **pq_ratio < 0.10 の専用対策**（現 EXP では改善せず）
   - pq_ratio-based weighted sampler の実装（現在は t-based のみ）
   - または pq_ratio 小サンプルのデータ収集強化

2. **t 極端値のターゲット収集**
   - t < 0: 現在 35件（test）→ 収集により少量で大改善の可能性
   - t > 1.2: 51件 → W4 で −20% 改善を確認、さらなる収集で上乗せ期待

3. **全体 MAE の改善経路**
   - ランダム追加の効果は学習曲線（EXP016）で飽和域に入っている
   - アーキテクチャ改善（backbone 強化・attention など）が次の有効手段の可能性
