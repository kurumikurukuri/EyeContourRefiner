# EXP004 考察まとめ: エッジケース学習改善 sweep

## 実験概要

**目的**: `use_sigmoid=False` + `use_t_norm=False` でモデルが生のt値（物理座標）を直接回帰させ、
t=0/1境界付近のエッジケース学習の改善を図る。

EXP002でのベスト設定（sig_tloss）はsigmoid出力でtを[0,1]に制約していた。
この制約がt<0やt>1のサンプル（輪郭の端点付近）の学習を妨げているという仮説に基づく。

- `use_sigmoid=False`: モデル出力を[0,1]に制約しない
- `use_distance_from_center`: point_index由来の端点位置情報を補助特徴量として追加
- `use_t_weighted_sampler (alpha=1.0)`: エッジ帯サンプルの過サンプリング（軽め）

## 実験条件

| 条件 | sigmoid | dfc | sampler (α=1.0) |
|------|---------|-----|-----------------|
| E1_no_norm | - | - | - |
| E2_no_norm_dfc | - | ✓ | - |
| E3_no_norm_sampler | - | - | ✓ |
| E4_no_norm_dfc_sampler | - | ✓ | ✓ |

ベースライン: EXP002 sig_tloss（CV=0.0643 / Holdout=0.0642、正規化tスケール）

## 結果

### 全体 MAE（生tスケール）

| 条件 | CV MAE | Holdout MAE | 全体 corr |
|------|--------|-------------|-----------|
| E1_no_norm | 0.1346 | 0.1343 | 0.448 |
| E2_no_norm_dfc | 0.1361 | 0.1361 | 0.443 |
| E3_no_norm_sampler | 0.1369 | 0.1350 | 0.440 |
| E4_no_norm_dfc_sampler | **0.1349** | **0.1342** | **0.459** |

**EXP002との比較（スケール換算）:**
EXP002 sig_tloss の生t換算: 0.0642 × 2.0（patch範囲 -0.5〜1.5） ≈ **0.1284**
→ EXP004 全条件がEXP002を下回っており、t正規化廃止は全体スコアの改善につながらなかった。

## 考察

### 1. エッジケースの平均回帰は解消されない

sigmoid廃止（出力非制約）にもかかわらず、エッジケースの平均回帰は全条件で深刻なまま:

- **t<0**（平均 −0.26）: 全条件で予測は +0.47〜+0.49 と逆方向に大きく外れる（MAE≈0.73〜0.75）
- **t>1**（平均 +1.15）: 予測は +0.67〜+0.69 にとどまり大幅な過小評価（MAE≈0.46〜0.47）

これはモデルの出力制約の問題ではなく、**学習データのクラス不均衡**が根本原因:
- 訓練データ構成: edge_low 3.1% / mid 71.9% / edge_high 25.0%（total 3150）
- t<0は全体の約1%にも満たず、モデルが学習不可能な量

### 2. dfc（distance_from_center）の効果はない

- E1→E2（dfc追加）: Holdout MAE +0.0018 悪化
- E3→E4（dfc追加）: Holdout MAE −0.0008 改善
- 効果はほぼゼロまたは微マイナス。point_index由来の端点位置情報は現状では有用な特徴量でない

### 3. サンプラー（alpha=1.0）の効果も限定的

- E1→E3（sampler追加）: Holdout MAE +0.0007 悪化
- EXP002でもalpha=1.0〜5.0が全てsig_tlossより悪化していた
- データが少なすぎるエッジ帯は過サンプリングしても情報は増えない

### 4. 全体相関係数が低い（r≈0.44〜0.46）

4条件とも相関係数が低く、モデルの識別力自体が問題。
sigmoid付き（EXP001 B1_sigmoid: r推定 ≈ 0.7以上）と比べて大幅に低い。
正規化なしでt値の分布が広がりすぎており、モデルが収束しにくくなっている可能性がある。

## 結論

| 項目 | 結論 |
|------|------|
| use_sigmoid=False | 逆効果。EXP002のsigmoid設定が全体精度では優れる |
| dfc特徴量 | 効果なし |
| サンプラー (alpha=1.0) | 効果なし |
| エッジケース改善 | 達成できず。原因はデータ不均衡（t<0は9件、t>1は35件） |

**次実験（EXP005）への示唆:**
エッジケースの改善に向けて、技術的なモデル制約の変更よりも
mid帯をダウンサンプリングしてエッジ帯への学習露出を増やす
データ戦略アプローチ（EXP005）の方向性が正当化される。
