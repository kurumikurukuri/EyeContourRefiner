# EXP031: 元画像空間の劣化オーグメンテーション（JPEG 圧縮 / 解像度ジッタ）

## 目的・仮説

パッチは元画像を補間拡大したものなので、パッチ空間で定義した劣化 augmentation は
元画像で実際に起きる劣化とスケールが一致しない、という仮説から出発する。
現行の BLUR/NOISE が有害であることまでは示していない。

以下は EXP031 の設定（枝A `perp_scale`・パッチサイズ）と manifest から見積もった値。
算出に使ったスクリプトはリポジトリに無く、再現手順は残っていない:

- **拡大率**: 枝A のパッチは元画像を t軸 **×1.40** / perp軸 **×3.50**（中央値）に拡大。
  perp 軸は 99.1% のサンプルで拡大側。
- **JPEG が完全に未模擬**。学習データ（Open Images 由来）も推論対象（アプリのカメラ画像）も
  JPEG なのに一度も模擬していない。元画像の 8×8 ブロックはパッチ上で **11.2px × 28.0px**
  （パッチ高さの 44%）を占める。逆にパッチ空間で JPEG を掛けると元画像換算 5.7×2.3px の
  非現実的なブロックになる。
- **現行 AUG_BLUR は実質 no-op**。σ 最大でも元画像換算 (0.71, 0.29) px。
- **解像度の分布幅が未活用**。`eye_scale` は p5=45px 〜 p95=169px と 3.7 倍の幅があり、
  低解像側を人工的に増やせば pq_ratio 小サンプルへの直接的な打ち手になりうる。

本実験は劣化を **ワープ前の元画像 ROI** に適用する 2 種を
2×2 直積で評価する。

**仮説**: 劣化を元画像ピクセル空間で定義し直せば、パッチ空間の劣化（実質 no-op ないし
off-manifold）と違って現実に起きる劣化を模擬でき、汎化が改善する。

**外部文献の裏付け**: 劣化を元解像度で定義するのは blind SR（Real-ESRGAN / BSRGAN）の
標準設計。また Kaggle Deepfake Detection Challenge 1 位解法（顔クロップパッチ）は
`ImageCompression(p=0.5)` と `IsotropicResize(AREA↓→CUBIC/LINEAR↑, p=1.0)` を使い、
対照的に `GaussNoise(p=0.1)` / `GaussianBlur(p=0.05)` は最低頻度に置いている。
本プロジェクトはこの優先順位が完全に逆だった。

**実験前からの懸念**: hold-out は学習データと同分布（`db_replica`）なので、
劣化耐性そのものは passrate に寄与しない。source 劣化が効くとすれば正則化としてか、
学習データ内に実在する低品質サンプルへの適合改善としてのみである。

## 実験設計・条件

- **実験ディレクトリ**: `experiments/EXP031_source_space_aug`
- **config 数**: 4（SD0_baseline, SD1_jpeg, SD2_resjitter, SD3_both）
- **テストセット**: EXP029 で採用が決まった `db_replica` 固定 manifest
  （EXP030 の manifest と SHA256 一致を確認済み、n_test=4900）

**固定条件**: bc32_pw8（base_channel=32, pool_width=8）+ k3_b32（k=3, batch=32）+
FLIP off（EXP021 Phase2 勝者）+ `endpoint_blend_range=0.25` + `loss_fn=t_l1` +
`fusion_mode=independent` + `pq_rescale_mode_b=eye_scale` + seed=42。
`perspective_aug` は無効。= EXP029 baseline / EXP030 AF0_baseline と同一構成。

**変動軸**: 元画像空間の劣化 2 種の 2×2 直積。ON/OFF は `aug_flags` のビットで指定する。

| config | aug_flags | JPEG (0x080) | 解像度ジッタ (0x100) |
|---|---:|:-:|:-:|
| SD0_baseline | 63 (0x03F) | − | − |
| SD1_jpeg | 191 (0x0BF) | ✓ | − |
| SD2_resjitter | 319 (0x13F) | − | ✓ |
| SD3_both | 447 (0x1BF) | ✓ | ✓ |

| 劣化 | パラメータ | 発火確率 |
|---|---|---|
| JPEG 圧縮 | quality ∈ [30, 90] | 0.5 |
| 解像度ジッタ | scale ∈ [1.0, 2.5]、INTER_AREA↓ → INTER_LINEAR↑ | 0.5 |

発火確率 0.5 は DFDC 1 位解法の `ImageCompression(p=0.5)` に合わせ、ablation の対称性の
ため両者を揃えた。両方発火した場合は **縮小 → 縮小サイズで JPEG → 拡大** の順（実世界では
低解像度で撮影された画像がその解像度のまま JPEG 保存されるため）。各劣化の発火は独立判定
なので、SD3 で両方発火するのは約 25%。

### 評価指標と判定基準

| 指標 | 定義 | 用途 |
|---|---|---|
| cv_mae | k=3 fold の val MAE 平均（正規化 t） | 学習の健全性確認 |
| holdout_mae (raw t) | 固定 hold-out n=4900 の MAE | 主指標 |
| pass_std / pass_strict | error_ratio ≤ 0.01788 (p10) / ≤ 0.01604 (p5) の割合 | 実運用基準 |
| paired t-test | per-sample abs error の対応比較（scipy `ttest_rel`） | 有意性判定 |

**採用条件**（すべて満たすこと）:

1. SD0_baseline に対し **ALL の paired t で有意な改善**（p<0.05, 改善方向）
2. pass_std が SD0_baseline を下回らない
3. cv_mae と holdout_mae の判定が一致している

**帯別の主張に課す再現性要件**（本再実験の結果を受けて追加）:

4. t 帯別の所見を結論に採用するには、**独立した 2 run で符号が一致し、かつ両方で有意**
   であること。
5. **n < 250 の帯（t<0: n=129 / 0-0.3: n=219 / t≥1.2: n=87）における単独 run の有意差は
   採用根拠にしない。** 本実験の 2 run 比較で、これらの帯の有意差は run 間で符号ごと
   入れ替わることが実測された（§再現性検証）。

**実装**（`eyeliner/data/source_degradation.py`、`dataset_dual.py` に配線）:

- パッチの footprint を元画像座標で算出し、その ROI にだけ劣化を掛けてからワープする
- ROI 原点は 8 の倍数に切り下げ、元画像の JPEG 8×8 ブロック格子に合わせる
- 劣化パラメータは 1 サンプルにつき 1 回だけ抽選し、枝A・枝B で共有する
- 劣化は train のみ（`augment_data=True`）。val / hold-out / 推論は全 config で入力が完全に同一

**実装中に検出・修正した不具合**: 当初は ROI を画像境界でクリップしていたが、footprint が
画像外へ出るサンプルで「全画像での BORDER_REFLECT_101」と「切り出し ROI での
BORDER_REFLECT_101」が別物になり、**最大 213/255・画素の 16%** がずれていた。目が画像端に
近いサンプルで劣化と無関係にパッチが壊れる状態だった。反射パディングで修正後、ランダム
6000 ケース（実データより極端な条件）で最大 8/255・不一致 0.85% 以下に収束。
検証は `tests/test_source_degradation.py`（43 件）。

**事前検証**: 実データ 400 サンプルで劣化の発火率 46.2% / 49.2% / 78.2%（期待 50/50/75）、
枝A/枝B の劣化同期 100%、ラベル完全不変を確認済み。

## 考察

- **改善方向の有意差はゼロ。仮説は支持されなかった。** SD1 の holdout MAE は SD0 を
  わずかに下回った（0.084104 vs 0.084326、−0.26%）が paired t で n.s.（p=0.609）であり、
  pass_std は逆に SD0 を下回る（88.90 vs 89.04）。採用条件 1・2 のいずれも満たさない。
- **cv_mae と holdout_mae の判定が一致しない。** cv_mae は SD0(0.029303) < SD1(0.029512)
  < SD2(0.029685) < SD3(0.029854) と劣化を足すほど単調に悪化する一方、holdout では
  SD1(0.084104) < SD0(0.084326) < SD3(0.085255) < SD2(0.085455) と SD1 が最良になる。
  採用条件 3 に抵触するため、SD1 の holdout 上の優位は根拠として採らない。
  初回実験では両者が同順だったので、**この不一致自体が run 間で変わる程度の差**である。
- **解像度ジッタ（SD2）だけが安定して有害。** ALL −1.34%（p=0.016 \*）で、唯一 ALL レベルで
  有意に悪化した条件。初回実験（−1.64%, p=0.002 \*\*）と符号・有意性ともに再現しており、
  再現性要件を満たす唯一の帯別・全体所見である。
- **SD3（両方）に交互作用は見られない。** ALL −1.10%（p=0.057）で、無害な SD1 と
  有害な SD2 の中間に位置する。相乗も相殺も観測されない。
- **N1 Affinity スクリーニングの順序は再現した。** 学習ゼロで測った摂動の強さ
  `src_res_jitter`（MAE ×1.119）> `src_jpeg`（×1.042）に対し、悪化幅は
  SD2 −1.34% > SD1 +0.26% と順序が一致。**今後の aug 候補は N1 で足切りしてから
  学習に回すべき**という初回実験の結論は維持される。
- 事前に記録した懸念——「hold-out が学習と同分布である以上、劣化耐性は passrate に
  寄与せず、劣化 aug は純粋な正則化ノイズとして働く」——と整合する結果になった。

## t帯別結果考察

- **初回実験で最も強調した「t<0 帯が 3 条件すべてで有意に悪化」は再現しなかった。**
  再現したのは SD2 のみ（−6.42%, p=0.013 \*）。SD1 は −10.60%（p=0.001 \*\*）から
  −2.63%（p=0.287 n.s.）へ、SD3 は −7.59%（p=0.010 \*）から −5.05%（p=0.074 n.s.）へ
  後退した。n=129 の帯における単独 run の有意差が、いかに脆いかを示している。
- **SD2 の 0-0.3 帯は符号ごと反転した。** 初回 −3.00%（n.s.）→ 再実験 **+3.42%（p=0.032 \*）**。
  同じ条件・同じ hold-out で、有意な悪化と有意な改善のあいだを行き来している。
  n=219 の帯の所見は単独 run では意味を持たない。
- **SD2 の「6 帯すべてで符号が負」も崩れた。** 再実験では 5/6 が負で、0-0.3 のみ正
  （しかも有意）。ただし ALL レベルの有意な悪化は再現しているため、
  「解像度ジッタは有害」という結論自体は帯別の内訳に依存しない。
- **多数派帯（0.3-0.7, 0.7-1.0, 合計 n=4114 = 全体の 84%）で有意差が出た条件は
  2 run を通じて 1 つもない。** SD1 の 0.7-1.0 が +1.23%（p=0.094）と最も改善方向に
  寄っているが、初回（+1.27%, p=0.083）と合わせても有意水準に届かない。
  劣化 aug が多数派帯に与える影響は、あるとしても検出限界以下である。

## ペア比較考察

- **SD1_jpeg vs SD0_baseline**: ALL +0.26%（p=0.609, n.s.）。6 帯すべて n.s.。
  初回実験で観測された「t<0 帯だけ −10.60% と大きく破壊する」現象は再現しなかった。
  JPEG 圧縮は**全体でも帯別でも検出可能な影響を持たない**、というのが 2 run を通じた解釈。
- **SD2_resjitter vs SD0_baseline**: **ALL −1.34%（p=0.016 \*）と唯一 ALL レベルで
  有意に悪化した条件**であり、初回実験と合わせて 2 run で再現した唯一の所見。
  **この軸は明確に有害と判定できる。**
- **SD3_both vs SD0_baseline**: ALL −1.10%（p=0.057, n.s.）。有意水準の境界だが
  初回（−0.57%, p=0.325）より悪化方向に振れており、run 間の振れ幅内。
  2 種の劣化に相乗効果も相殺効果も観測されない。
- 2 run を通じて安定しているのは「**改善方向の有意差はどの条件にも存在しない**」
  「**解像度ジッタは ALL レベルで有意に有害**」の 2 点のみ。それ以外の帯別所見は
  run 間で符号ごと入れ替わる。

## 再現性検証（初回 2026-08-13 / 再実験 2026-08-15）

`source_jpeg` / `source_res_jitter` の bool キーを `aug_flags` のビットへ統合した
リファクタ後、SD1/SD2/SD3 を同一 config・同一 seed で再学習した。

### リファクタの挙動同一性（統計ではなくビット比較で確認）

| 検証 | 結果 |
|---|---|
| 旧経路 `aug_flags=63 + source_jpeg=True` vs 新経路 `aug_flags=191` の `SourceDegradeConfig` | 4 条件すべて完全一致 |
| 同 2 経路が生成する学習パッチ（120 サンプル, seed 固定, NOISE 無効） | **ビット一致（最大差 0.000e+00）** |

**リファクタは学習挙動を一切変えていない。**

### 初回 run と再実験 run の差（同一 hold-out の per-sample 対応差）

| config | holdout MAE 初回 | 再実験 | 平均対応差 | 95% CI | p |
|---|---|---|---|---|---|
| SD1_jpeg | 0.084521 | 0.084104 | −0.000418 | [−0.00125, +0.00042] | 0.326 n.s. |
| SD2_resjitter | 0.085713 | 0.085455 | −0.000258 | [−0.00109, +0.00058] | 0.544 n.s. |
| SD3_both | 0.084806 | 0.085255 | +0.000449 | [−0.00028, +0.00117] | 0.225 n.s. |

ALL レベルでは 3 条件とも有意差なし、95% CI はすべてゼロを跨ぐ。
一方 t 帯別では有意差が出る（SD1 の t<0 で p=0.015、SD2 の 0-0.3 で p<0.0001 など）。

### 差の原因: NOISE の RNG が seed 管理外（bug1）

同一コード・同一 seed で 2 回データを生成して比較した実測:

| 条件 | 結果 |
|---|---|
| `aug_flags=191`（NOISE 有効）を 2 回 | 最大差 5.670e-01 / **ビット不一致** |
| `aug_flags=187`（NOISE のみ無効）を 2 回 | 最大差 0.000e+00 / **ビット一致** |

原因は `eyeliner/data/augmentation.py` の `np.random.default_rng()` を引数なしで毎回
呼んでいる箇所。OS エントロピーから毎回新しい生成器が作られるため、`random.seed()` も
`np.random.seed()` も効かない。`AUG_NOISE` は発火確率のゲートがなく毎サンプル必ず通る。
（差が 0.567 と大きいのは ImageNet 正規化で 1/std ≈ 4.4 倍に増幅されるため）

したがって **本プロジェクトの学習は seed を固定しても再現しない**。GPU 非決定性
（CuBLAS / `adaptive_avg_pool2d_backward_cuda`）もこれに加算される。

比較スクリプト: `analyses/exp031_rerun_check/scr/compare_rerun.py`

## 結論

- **JPEG 圧縮・解像度ジッタとも不採用。** 2 run を通じて改善方向の有意差は 1 つも
  得られなかった。本実験の仮説「劣化を元画像 px 空間で定義すれば汎化が改善する」は
  **本実験では支持されなかった**。
- **解像度ジッタ（SD2）は明確に有害。** ALL −1.34%（p=0.016 \*）が 2 run で再現。
  この軸は今後の候補から外してよい。
- **JPEG（SD1）は影響が検出できない。** 初回実験は「t<0 帯を −10.60% 破壊する」と
  結論したが、再実験では −2.63%（n.s.）で再現しなかった。**全体でも帯別でも有意差なし**が
  2 run を通じた妥当な解釈。害がある証拠も益がある証拠も無い。
- **副次的な成果として、N1 Affinity スクリーニングの有効性が実証された。**
  学習ゼロで測った摂動の強さの順序（res_jitter > jpeg）が、5〜6 時間 ×3 config の学習を
  経た悪化幅の順序と一致した。**今後の aug 候補は N1 で足切りしてから学習に回すべきである。**
- **最大の教訓は方法論側にある。** 小サンプル帯（n<250）の単独 run の有意差は、
  符号ごと入れ替わる程度に不安定だった。初回実験の「t<0 帯が一貫して悪化」という
  最も強調された所見は、再実験でほぼ消えた。**帯別の主張には 2 run の再現を要件とする**
  （§判定基準 4・5）。
- ただし本実験は「劣化耐性」そのものは測っていない。同分布 hold-out で改善しないことと、
  実運用（品質のばらつくカメラ画像）で無価値であることは別問題である（下記課題）。

## 追加検証: SD4_endpoint_only（photometric aug 全体の寄与）


**条件**: `aug_flags=32`（0x020）— BRIGHTNESS/BLUR/NOISE/COLOR_TEMP/GRAYSCALE の
photometric 5 種を全 OFF にし、幾何系（R 保存）の ENDPOINT_BLEND のみ有効。FLIP は
SD0_baseline と同じく off。source 系（JPEG/解像度ジッタ）も SD0_baseline と同じく off。
比較対象は `aug_flags=63`（photometric 5 種 + ENDPOINT_BLEND 全 ON）の SD0_baseline。

**考察**:

- **photometric augmentation ブロックを丸ごと外すと ALL で有意に悪化する
  （-3.49%, p<0.001）。** EXP001〜EXP031 を通じて初めて photometric ブロック全体の
  寄与を測った結果であり、単発の帯別所見ではなく ALL レベルの高い有意性を伴う。
- **最大の悪化は多数派帯 0.7-1.0（n=2430, 全体の 50%）で -5.57%（p<0.001）。**
  本実験の主軸（SD1〜SD3）ではこの多数派帯で有意差が一度も出なかった
  （§t帯別結果考察参照）ことと対照的に、photometric aug の除去は多数派帯に
  はっきり検出可能な悪影響を与える。
- **t<0 帯（n=129）は -15.52%（p<0.001）と全条件中最大の悪化幅。** n<250 のため
  単独所見としての採用条件は満たさない（§判定基準5）が、ALL・多数派帯の悪化と
  符号が一致しており、傾向としては整合的。
- 0-0.3 / 0.3-0.7 / 1.0-1.2 / t>=1.2 は n.s.。0.3-0.7 のみ符号が改善方向
  （+1.55%, n.s.）だが有意ではない。

**結論（追加検証）**: **photometric augmentation（BRIGHTNESS/BLUR/NOISE/COLOR_TEMP/
GRAYSCALE）は明確に有益であり、無効化は不採用。** 現行の既定値 `aug_flags=63`
（photometric 全 ON + ENDPOINT_BLEND）を維持する。EXP030 で個々の発火頻度
sweep（aug_prob）は据え置きと結論したが、本追加検証は「ブロック全体の有無」という
より粗い軸で見ても現行設定が root から正当化されることを裏付けた。

## 今後の課題

- **bug1（NOISE の RNG が seed 管理外）の修正。** 本再実験で実測確認した（§再現性検証）。
  修正は 1 行だが**乱数列が変わり過去の全結果と非互換**になるため、実施タイミングは
  次の実験の切れ目に合わせる必要がある。修正しない限り、seed 固定による再現も、
  run-to-run 分散の正しい見積もりもできない。
- **劣化を掛けた hold-out での副次評価が未実施。** 本実験は clean な hold-out でしか
  評価していない。劣化 hold-out で SD1/SD2 が SD0 を上回るなら、
  「同分布性能を犠牲に劣化耐性を得た」というトレードオフとして再評価の余地が残る。
  逆に劣化 hold-out でも改善が無ければ、この軸は完全に棄却できる。**これを先に実施すべき。**
- **より弱い設定での再試行。** 発火確率 0.5 と scale 上限 2.5 は摂動量を事前に測らずに
  決めたが、SD2 の ALL レベルの悪化は「強すぎる」ことを
  示唆する。scale 上限 1.5 や発火確率 0.25 での再試行には意味がありうる。
  ただし N1 Affinity で事前に摂動量を測ってから決めること。
- **S1（BLUR/NOISE を元画像 px 空間で再定義）は未実施。** 本実験は JPEG 圧縮・解像度ジッタのみを扱った。
  冒頭の見積もりでは現行 BLUR は元画像換算 σ=(0.71, 0.29)px と小さいが、
  実質 no-op かどうかは S1 を学習で比較するまで確定しない。
- **`aug_flags=32`（photometric 全 OFF）は検証済み（2026-08-16, §追加検証: SD4_endpoint_only）。**
  ALL -3.49%（p<0.001）で明確に有害と判定、現行の photometric ブロックは維持と結論。
  なお同じ計測では、パッチ空間 aug は
  データ生成コストの +0.62 ms/sample を占め（source 劣化は +0.13 ms/sample）。
- **N7 Fourier Heat Map が別方向を示唆している。** 本モデルは高周波の摂動にほぼ無反応
  （×1.005）である一方、低周波では ×1.248 まで劣化し、とくに **t 軸方向に振動する縞**に
  最も脆弱（最大 ×1.59）だった。これは「誤検出の主因は平行する偽エッジ」という見方

  perp 軸は P→Q の 90° 回転なので左右眼で向きが反転しうる（`eyeliner/data/patch_utils.py`）。
  その向きの違いをモデルが区別していることを示唆しており、
  **EXP033（S2 対側眼 aug / 正準化 / `is_left_eye` aux）の優先度を上げる材料**になる。
