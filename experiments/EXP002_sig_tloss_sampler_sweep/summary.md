# EXP002 考察まとめ: sigmoid + t_loss 組み合わせ & サンプラー sweep

## 実験概要

**目的**: EXP001 の知見（sigmoid と t_loss が独立して有効）を踏まえ、両者を組み合わせた場合の効果と、
エッジケース対策としての重み付きサンプラー（t_weighted_sampler）の有効性を検証する。

EXP001 のベストが B1_sigmoid (CV: 0.065844) と A2_t_loss (Holdout: 0.066788) に分かれており、
その組み合わせ C1_sig_tloss が主軸となる。

バックボーンは全条件 `custom`（3層CNN）固定。

## 実験条件

| 条件 | loss_fn | sigmoid | t_weighted_sampler | t_weight_alpha | 比較対象 |
|------|---------|---------|-------------------|----------------|----------|
| C1_sig_tloss | t | ✓ | - | - | 主軸：B1+A2の組み合わせ |
| C2_sampler_a1 | t | ✓ | ✓ | 1.0 | サンプラー弱め |
| C3_sampler_a3 | t | ✓ | ✓ | 3.0 | サンプラー標準 |
| C4_sampler_a5 | t | ✓ | ✓ | 5.0 | サンプラー強め |
| C5_sampler_nosig | t | - | ✓ | 3.0 | サンプラー単独効果の単離 |

## 考察

### 1. sig_tloss が EXP001 ベスト(B1_sigmoid)を明確に上回る

- Holdout MAE: B1_sigmoid 0.0667 → **sig_tloss 0.0642 (-3.7%)**
- CV MAE:     B1_sigmoid 0.0660 → sig_tloss 0.0643 (-2.6%)
- CV と Holdout がほぼ同値（0.0001差）で汎化が安定している

sigmoid の出力制約と t_loss の物理単位損失は **独立して寄与**し、
組み合わせたときに加算的な改善をもたらすことが確認された（EXP001 の仮説を検証）。
以降の実験ではこの構成を標準ベースラインとする。

### 2. t_weighted_sampler は α を問わず逆効果

sig_tloss 基準の Holdout MAE 差分:

| α | Holdout 差分 | CV 差分 | 相関係数 差分 |
|---|-------------|---------|--------------|
| 1.0 | +0.0014 | +0.0003 | -0.008 |
| 3.0 | +0.0011 | +0.0004 | -0.010 |
| 5.0 | +0.0026 | +0.0010 | -0.037 |

α が大きくなるほど悪化。**サンプラーは中間帯 (mid) の MAE を押し上げる**（0.079→0.084）のに
対して、エッジ帯の MAE 改善はほぼゼロ（t<0, t>1 で依然として平均回帰）。
少数クラスをオーバーサンプリングしても、**t<0 / t>1 の絶対サンプル数が少なすぎて
モデルが学習できず、中間帯の精度だけ犠牲になる**というトレードオフが生じている。

### 3. sampler_nosig（sigmoid 無し + sampler）は最悪条件

CV 0.0695 / Holdout 0.0681 / corr 0.445 と全条件で最悪。
EXP001 A2_t_loss（CV 0.0703 / Holdout 0.0679）とほぼ同等であり、
**sampler 単独の効果はほぼゼロ**。t_loss の正則化効果も打ち消される。
sigmoid の出力制約なしでは t_loss が収束しにくいという EXP001 の観察と整合する。

### 4. 平均回帰バイアスは sigmoid+t_loss でも解消されない

全条件で `t<0` の予測は +0.47〜+0.51、`t>1` の予測は +0.69〜+0.70 に収束しており、
モデルは範囲外サンプルを **全く学習できていない**。これは sigmoid 出力制約 [0,1] の
根本的な限界と、訓練データ不均衡（t<0 が 3% 未満、t>1 が数%）が主因。

**EXP004（use_sigmoid=False）や EXP005（mid ダウンサンプル）がこの課題に挑む動機となる。**

### 5. mid 帯の識別力が限定的（r≈0.48）

全体相関 r=0.48 は中程度。mid 帯 (0.2-0.8) で MAE=0.079 と良好だが、
`0.8<t≤1` では MAE=0.145 と 2 倍近く悪化し、末端近くの識別力が弱い。
EXP003 以降で patch 範囲や解像度の工夫で改善を試みる。

## 結論

| 項目 | 結論 |
|------|------|
| sigmoid + t_loss 組み合わせ | ✅ 採用。EXP001 最良単独構成より -3.7% |
| t_weighted_sampler | ❌ α=1〜5 全てで逆効果。以降不採用 |
| sampler + sigmoid 無し | ❌ 最悪条件。sampler 単独効果なし |
| エッジケース改善 | ❌ 達成できず。データ不均衡が根本原因 |

**次実験（EXP003）への示唆:**
sig_tloss を固定して入力パラメータ（patch_t 範囲、垂直範囲、解像度）の
体系的 sweep に進む。特に patch 範囲を広げることで t<0 / t>1 近傍の
コンテキストをモデルに提供できるかを検証する。
