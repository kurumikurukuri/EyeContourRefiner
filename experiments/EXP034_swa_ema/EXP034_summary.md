# EXP034: 重み平均（EMA / SWA）の効果検証（seed 42）

## 目的・仮説

現行dual標準は OneCycleLR（200 epoch 前提）の途中で早期終了しており、停止時も lr が最大値付近
（EXP033 のログで約 9.6e-4）のままで、最終重みが揺れている。また EXP033 では 3 seed アンサンブルが
単体比 −1.4% 改善し、誤差の一部が平均で打ち消せる「重みの揺れ」由来であることが示唆された。

**仮説**: 重み平均（EMA / SWA）で 1 モデル内の揺れを打ち消せば、推論コストを変えずに改善する。

## 実験設計・条件

- **実験ディレクトリ**: `experiments/EXP034_swa_ema`
- **config 数**: 4
- **config 一覧**: base, base_ema0999, base_ema09998, base_swa
- **評価指標**: cv_mae, holdout_mae(raw t), passrate(std/strict)
- **passrate 閾値**: std=0.01788 (p10), strict=0.01604 (p5)
- **検定方法**: scipy paired t-test（per-sample abs error）

**1 回の学習（seed=42）から 4 モデルを作り、同一 run 内で paired 比較する**。EXP033 で、同一 seed の
再学習でも GPU の非決定性で帯別に有意差が出ると分かったため、run 間の差を比較から排除した。

| config | 作り方 |
|---|---|
| base | 早期終了（patience 50）で選んだ val 最良 = 現行dual標準（EXP033 dual_s42 と同一構成） |
| base_ema0999 | EMA decay=0.999（半減期 ≈ 2 epoch）。毎ステップ更新、BN の running stats も平均。val 最良 epoch を保存 |
| base_ema09998 | EMA decay=0.9998（半減期 ≈ 10 epoch）。同上 |
| base_swa | base の val 最良重みから lr=2.5e-4 一定（AdamW）で 30 epoch 追加学習し、各 epoch 末を等重み平均。BN 統計は train で再計算 |

- 早期終了の判定は base の val のみ。EMA の評価・SWA は乱数状態を保存・復元して行うため、base の
  学習は EMA/SWA 無効時とビット単位で同一（`tests/test_dual_kfold.py` で検証）。
- 固定条件・manifest（db_replica）は EXP033 と同一。全モデル同一構造のため推論コスト・ONNX 互換性は不変。
- 実装: `eyeliner/training/weight_averaging.py`・`dual_epoch.py`・`dual_averaging.py`、
  `DualTrainConfig.ema_decays / swa_epochs / swa_lr`（既定は無効）。

## 考察

### CV（fold 単体の val MAE、枝A正規化）

| config | fold1 | fold2 | fold3 | 平均 | vs base |
|---|---|---|---|---|---|
| base | 0.029640 | 0.028478 | 0.030135 | 0.029418 | — |
| base_ema0999 | 0.029155 | 0.027934 | 0.029525 | 0.028872 | −1.86% |
| base_ema09998 | 0.029143 | 0.027798 | 0.029468 | 0.028803 | −2.09% |
| base_swa | 0.029690 | 0.028607 | 0.030218 | 0.029505 | +0.30% |

（EMA の最良 epoch: ema0999 = 74/91/77、ema09998 = 110/98/99。base は 126/109/130）

### fold 単体モデルの hold-out MAE（生t、`scr/per_fold_holdout_exp034.py`）

| config | fold1 | fold2 | fold3 | 平均 | vs base |
|---|---|---|---|---|---|
| base | 0.087171 | 0.088356 | 0.088703 | 0.088077 | — |
| base_ema0999 | 0.086853 | 0.086644 | 0.087495 | 0.086998 | −1.23% |
| base_ema09998 | 0.086216 | 0.085734 | 0.087319 | 0.086423 | **−1.88%** |
| base_swa | 0.087637 | 0.088001 | 0.089416 | 0.088352 | +0.31% |

### 解釈

- **EMA は fold 単体モデルを確実に改善する**: hold-out でも 3 fold すべてで base より良く、
  decay=0.9998 で −1.88%。CV の改善（−2.09%）がほぼそのまま hold-out に転移している。
- **しかし 3 fold アンサンブル（本番・評価の形）では効果が消える**: アンサンブルの hold-out MAE は
  base 0.083636 / ema09998 0.083540（+0.12%, p=0.78）/ ema0999 0.084183（−0.65%, p=0.15）。
  fold アンサンブル自体が単体比 −5.0%（0.088077 → 0.083636）の平均化を既に行っており、
  EMA が打ち消す「重みの揺れ」はアンサンブルでも打ち消される同じ成分だったため、効果が重複して吸収された。
- **SWA は効果なし**: 一定 lr=2.5e-4 の追加学習中、平均前の val は 30 epoch かけて緩やかに悪化
  （例: fold1 0.02978 → 0.03001）。最良重みから離れる方向の追加学習を平均しても base を超えなかった。
  base の最良重みは既に良い谷にあり、そこからの探索幅が小さかったと考えられる。
- 3 fold アンサンブル base の hold-out（0.083636 / pass_std 89.10%）は EXP033 の 3 seed 範囲
  （0.0843〜0.0847）より良い側だが、EXP033 の seed ばらつき（sd 0.00023）の約 3.6 sd 外で、
  run 間の非決定性を考えると「この run がたまたま良い」以上の解釈はしない。

## t帯別結果考察

- EMA は 2 つの decay とも、t<0（−9.6〜−10.4%）・0-0.3（約 −5.7%）で悪化、1.0-1.2（+4.0〜+4.5%）・
  t>=1.2（+6.2〜+7.8%）で改善と、同じ向きの帯間トレードオフを示した。
- SWA は 0.3-0.7（−4.4%）で悪化、1.0-1.2（+7.5%）・t>=1.2（+8.4%）で改善。
- ただし EXP033 で、seed 違い・同一 seed の再学習だけで t<0 は ±10%、0.3-0.7・1.0-1.2 は ±4% 揺れ、
  p<0.001 の差が出ることが分かっている。2 つの EMA は同一 run の重み平均なので互いに独立な再現でもない。
  **本実験の帯別差は採用根拠にしない**（「高 t 帯に効く」可能性は複数 seed での確認待ち）。

- 全体はいずれも n.s.（ema0999 p=0.149、ema09998 p=0.776、swa p=0.146）。EXP033 の判定基準

## 結論

**EMA・SWA とも、現行の 3 fold アンサンブル構成では不採用。**

- EMA は fold 単体モデルを hold-out でも約 −1.9% 改善する（3 fold すべてで改善）が、3 fold アンサンブルに
  すると効果が消える。重み平均とアンサンブルが打ち消すのは同じ「重みの揺れ」成分だった。
- SWA（base 最良から lr 一定で追加学習）は単体・アンサンブルとも効果なし。
- **EMA が意味を持つのは、本番を単体モデルにする場合**: 単体 EMA（0.086423）はアンサンブル base
  （0.083636）より 3.3% 悪いが、推論コストは 1/3。速度を優先して fold アンサンブルをやめるなら、
  単体モデルには EMA（decay=0.9998）を使うべき。
- 副次的な知見: EXP033 の seed アンサンブル（−1.4%）も、fold アンサンブルに対して「重みの揺れ」の
  平均化を上乗せしたもの。fold アンサンブル内の 3 モデルは既に揺れの一部を打ち消しているので、
  さらなる平均化の効き目は小さくなっていく。

## 今後の課題

- **単体モデル + EMA で本番の推論を 1/3 にする案の評価**: 速度・配布サイズを優先する場合の候補。
  単体 EMA と 3 fold アンサンブルの差（約 3.3%）を許容できるかは face_makeup 側の要件次第。
- **EMA モデルの蒸留教師化**: EMA で滑らかになった単体モデルは、アンサンブル蒸留（次実験案 2）の
  教師・生徒どちらにも使える。
- **SWA の設定**: 本実験は lr=2.5e-4・30 epoch の 1 設定のみ。OneCycle の後半（lr が下がる区間）を
  早期終了せず走り切ってから平均する構成や、cyclic lr は未検証。ただしアンサンブルで効果が吸収される
  構造は EMA と同じなので、優先度は低い。
- 帯別のトレードオフ（EMA・SWA とも高 t 帯で改善・低 t 帯で悪化）が本物かは、複数 seed で確認が必要。
