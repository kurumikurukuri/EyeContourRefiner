# EXP008: norm_eye_scale sweep

## 目的

`norm_eye_scale`（画像解像度正規化済み eye_scale = eye_scale / sqrt(img_H × img_W)）を
モデルのスカラー補助入力として追加したときの効果を検証する。

**仮説**: 目のサイズ情報を与えることで、小さい目での t 予測精度が改善する。
wide patch range 構成（H2）との組み合わせが最も恩恵を受けやすい。

## 考察

### 1. norm_eye_scale / pq_ratio ともに有意な効果なし

- J2_wide_patch_nes は H2_wide_patch より **わずかに悪化**（raw MAE +0.0019）
- J4_wide_patch_pq_ratio も同様に **わずかに悪化**（+0.0015）
- J1（H1ベース + nes）は H1 と完全同値、J3（H1ベース + pq_ratio）は -0.001 の微改善だが誤差範囲内
- 相関係数でも H2(0.626) > J2(0.615) ≈ J4(0.616) > J3(0.585) > J1(0.577) ≈ H1(0.569) と、wide_patch による改善を上回る補助入力の寄与は見られない

### 2. wide_patch × 補助入力の組み合わせも効果なし

H2 → J2/J4 でいずれも MAE 悪化、r もわずかに低下。
**wide_patch 構成（patch_t=-1.0〜2.0）自体で十分なコンテキストが提供されているため、
スカラー補助入力を追加する恩恵が相殺されている**と考えられる。

### 3. バイアスパターンは補助入力で変化しない

t<0.2 の過大予測（+0.40〜+0.42）、t>1 の過小予測（-0.31〜-0.35）は全条件で一致。
norm_eye_scale も pq_ratio も平均回帰バイアスの根本原因（t分布の不均衡）には
作用せず、**スカラー補助入力では端点予測の識別力を向上できない**ことが確認された。

### 4. EXP001 A3_pq_ratio の知見と整合

EXP001 では A3_pq_ratio が A1_baseline と同等（効果なし）と結論づけていた。
データ増加後（EXP006→EXP008）でも同じ結論が維持され、
**pq_ratio は一貫して有用な補助入力ではない**ことが追認された。

## 結論

**norm_eye_scale・pq_ratio いずれも有効ではない。採用しない。**

- 全4条件が EXP006 の対応するベースラインと同等〜わずかに悪化
- 相関係数も改善せず
- バイアスパターンも変化なし
- EXP006 H2_wide_patch が引き続きベストモデル（生t MAE = 0.1267）

**次実験への示唆:**
スカラー補助入力では限界。
- 空間情報（パッチ内の位置 encoding / attention）
- より多様なデータ（EXP010 のデータ v2 で検証）
- 端点専用の損失重み付け（EXP011 の t_weighted_loss で検証）
の方向へシフトすべき。
