## 次実験への提言（EXP012）

**E6 × F3 × C03 の組み合わせ実験を推奨**

```yaml
# 推奨設定
backbone: custom
num_conv_layers: 5       # F3 より
lr: 1.0e-3               # E6 より
weight_decay: 1.0e-4     # E6 より
loss_fn: t_weighted      # C03 より
use_t_weighted_sampler: true
t_weight_alpha: 1.0      # C03 より
t_loss_alpha: 3.0        # C03 より
batch: 16                # H1〜H2 参考
aug_flags: 79            # 現状維持（flip・color_temp 必須）
```

- E6 単独 -0.0039、F3 単独 -0.0034 の改善があり、組み合わせで **test MAE 0.110〜0.111 台**が期待できる
- F3 の gap (0.0282) が大きいため、Dropout or L2 の追加を検討
- E7 の崩壊事例から、lr=1e-3 × wd=5e-4 の組み合わせは避けること
