# EXP036: PQ 回転摂動 augmentation の 3 seed 確認

## 目的・仮説

[EXP035](../EXP035_pq_jitter/EXP035_summary.md) の 1 seed スクリーニングで、PQ 回転摂動 J3(±15°) / J4(±20°) は
J0 比 −3.27% / −3.73%（p<1e-6）と有望だった。ただし seed は 42 のみで、J3〜J5 は結果を見て追加した条件のため
選択バイアスがある。本実験では 3 seed で以下を確認する。

1. 回転摂動の改善が seed ノイズ（[EXP033](../EXP033_seed_variance/EXP033_summary.md): 全体 MAE の seed 間 range 0.52%）を超えるか
2. J3 と J4 のどちらが安定して良いか
3. seed 平均の pass_std が努力目標 90% を超えるか

## 実験設計・条件

- **config**: `experiments/EXP036_pq_jitter_seed/config/{J0,J3,J4}_s{42,43,44}.yaml`（3 条件 × 3 seed = 9 run）
- **主要ハイパーパラメータ**: 現行dual標準（EXP035 J0_base と同一）。epochs=200, batch=32, lr=1e-3, wd=1e-4, patience=50, k=3, bc32_pw8
- **固定する条件 / 変える条件**: 回転幅 θmax（J0=なし / J3=±15° / J4=±20°）と seed（42/43/44）のみ変える。
  seed 42 は EXP035 の再現確認を兼ねる（実験独立性のため EXP035 の outputs は流用せず再学習）
- **データ**: EXP029 db_replica 固定 manifest（EXP035 と同一ファイル、train 16,548 点 / test 4,900 点）
- **評価指標**: cv_mae, holdout_mae(raw t), passrate(std/strict)。閾値は`experiments/Completion_Criteria.md`準拠
- **検定方法**: scipy paired t-test（per-sample abs error）。**同一 seed 内**で J3/J4 vs J0、および J4 vs J3
- **3 seed アンサンブル**（`{cond}_ens3`）: 同条件 3 seed の t_pred 平均（各 seed は fold 3 本のアンサンブル済み）。参考値

### 判定基準

1. **採用**: 3 seed 平均の全体 MAE 改善が 0.52% を超え、かつ seed ごとの paired t-test（vs 同 seed の J0）が
   3 seed すべてで改善方向・p<0.05
2. **J3 / J4 の選択**: seed 平均の差が seed 間 SD 以内なら、0-0.3 帯の副作用が小さい J3 を優先
3. **完了条件**: seed 平均の pass_std が 90% を超えるか（参考として 3 seed アンサンブルの pass_std も記録）
4. **帯別**: 3 seed で符号が揃った場合のみ所見として記載し、採用根拠にはしない

## 考察

- **回転摂動の改善は seed ノイズを大きく超える**。seed 平均で J3 −3.16%、J4 −3.27% と、
  EXP033 の seed 間 range（0.52%）の約 6 倍。同一 seed 内の paired t-test は J3・J4 とも 3 seed すべてで p<0.001。
  条件間の差（J0 と J3/J4 で約 0.0027）は、条件内の seed SD（0.0001〜0.0008）より 1 桁大きい。
- **EXP035 の seed 42 はほぼ再現した**: J0 0.08429 → 0.08396、J3 0.08153 → 0.08146、J4 0.08114 → 0.08169。
  EXP035 で J4 が J3 を上回った（+0.47%）のは再現せず、今回の seed 42 では J3 が J4 より 0.28% 良い（n.s.）。
  EXP035 の「J4 が最良」は 1 seed のゆらぎだったと考えられる。
- **J3 と J4 は区別できない**: seed 平均の差は 0.000096（0.12%）で J3 の seed SD（0.00051）より小さく、
  同一 seed 内の J4 vs J3 も 3 seed とも n.s.（p=0.59 / 0.87 / 0.15）で符号も揃わない（−0.28% / −0.08% / +0.70%）。
  J4 は seed SD が特に小さい（0.000084）が、3 seed で SD を比べられるほどの精度はない。
- **J0 の seed 平均 0.08452 は EXP033（0.08447 ± 0.00023）と一致**。J0_s44（0.08537）は 3 seed で最も悪く、
  J0 の SD（0.00075）は EXP033 の約 3 倍。その分 seed 44 では J3/J4 の改善幅が大きく出ている（−3.45% / −4.13%）。
- **3 seed アンサンブル**は J0 −1.4%、J3 −1.2%、J4 −1.2%（各条件の seed 平均比）。アンサンブル同士でも
  J3/J4 は J0 に対し −2.95% / −3.13%（p<1e-6）で、改善幅はアンサンブル後もほぼ保たれる（seed 平均の改善と加算的）。

  **判定基準 2 で J3 優先の理由とした「0-0.3 の副作用が J3 のほうが小さい」はデータでは確認できなかった**
  （0-0.3 の seed 平均改善率は J3 −2.4%、J4 −3.0%）。
- 帯別の差は採用根拠にしない（判定基準 4）。

## ペア比較考察

- 採用判定の主軸は同一 seed 内の J3/J4 vs J0（上表 ALL 列）で、6 比較すべて p<0.001。
- `scripts/paired_ttest.py` の出力 JSON は `outputs/ttest_{target}_vs_{baseline}.json`（同一 seed 内の 9 比較 + アンサンブルの 3 比較）。
  `generate_summary.py` は単一 baseline に対し全 config を比べるため、seed をまたいだ比較になり本 summary では使っていない。
- 参考として J0 同士の seed 間比較（J0_s43 / J0_s44 vs J0_s42）でも、0.7-1.0・1.0-1.2・t>=1.2 で p<0.05 の差が出る
  （例: J0_s44 は 1.0-1.2 で −5.13%、p=0.0055）。EXP033 と同様、**1 seed の帯別 p 値は採用根拠にならない**ことを再確認した。

## 結論

- **PQ 回転摂動を採用する**。J3・J4 とも判定基準 1（seed 平均改善 0.52% 超、3 seed すべて p<0.05）を満たした
  （J3 −3.16%、J4 −3.27%、全 6 比較で p<0.001）。EXP035 の 1 seed スクリーニングの結論は 3 seed でも成り立つ。
- **回転幅は事前に決めた基準に従い J3（±15°）を標準にする**。J3 と J4 の差は seed SD 以内で区別できない。
  ただし J3 を選ぶ根拠とした「0-0.3 の副作用が小さい」は確認できず、実質は「同等なので摂動の小さいほうを選ぶ」判断である。
  J4 を選んでも結果はほぼ変わらない。
- **次の標準構成**: 現行dual標準 + `aug_flags: 575`、`pq_jitter_rot_deg: 15.0`、`pq_jitter_prob: 1.0`。
- **努力目標 pass_std 90%** は単体モデルの seed 平均では未達（89.62%）。J3 の 3 seed アンサンブルでは 90.10% に達する。
- 0-0.3 帯の小さな悪化（−1〜−5%）は 6 run すべてで同じ向きに出ており、回転摂動の副作用として残っている。

## 今後の課題

- **0-0.3 帯の悪化の原因**: 内側寄り（R が Q 付近）の点で、回転により P 側が大きく振られ、パッチとラベルの対応が崩れる可能性がある。
  R からの距離に応じて回転を弱める、あるいは 0-0.3 帯の点だけ回転確率を下げる案で、副作用を消せるか検討する。
- **回転幅の分布**（EXP035 からの持ち越し）: U(±15°) を N(0, σ) や prob<1 に置き換え、0-0.3 の悪化を抑えつつ効果を保てるか。
- **pass_std 90% への残り約 0.4pt**: seed アンサンブル（推論 3 倍）を許容するか、EMA（EXP034 で単体 fold が −1.88%）と組み合わせて
  単体モデルで届くかを検討する。
