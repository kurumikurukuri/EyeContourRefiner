# EXP013: ハイパーパラメータ組み合わせ検証（L7 ベース × lr/conv/twl/正則化 × label 範囲）

## 目的・仮説

- EXP010 の L7（`wide_patch_deep4`, conv4・aug=79）と EXP012 の推奨パッチ（`patch_w=64 / patch_h=64 / perp_scale=1.0`）をベースに、EXP011 で **単体効果が確認された** 3 因子（`lr=1e-3` / `conv5` / `t_weighted_loss α=3`）の **組み合わせ効果** を検証する。
- さらに、`label_t_min / label_t_max` を広げた条件と `patch_t_min / patch_t_max` を広げた条件の影響を確認する。
- 仮説: 単体効果が加算的に効くならベスト構成（Q6）は Q1（EXP012 ベースライン）を 0.005 以上上回る。

### エッジケース的観察

- Q6（本命）と Q1（ベースライン）の test_mae 差は `+0.0003`（ベースラインの方がわずかに良い）。加算効果が **まったく観測されない**。
- Q0（`patch_w=128`）と Q1（`patch_w=64`）の差は `+0.0008`（Q1 優位）。EXP012 の結論「`patch_w=64` で十分」と整合。

## 考察

### 1. 「単体効果の加算性」は成立しなかった

EXP011 では `lr=1e-3`（E6）・`conv5`（F3）・`t_weighted_loss α=3`（C03）がそれぞれ単体で僅少の改善を示した。本実験で **全部乗せ** した Q6 は Q1 比で改善ゼロ（むしろ微悪化）。

- EXP011 の単体効果自体が **測定誤差レベル** だった可能性が高い（実際 EXP011 の test_mae 差も 0.001〜0.002 程度）。
- 単体で効いた因子同士が **独立でなく干渉** している可能性（例: `lr=1e-3` + `conv5` は最適化が不安定化しやすく、`dropout=0.1` への緩和でも補いきれない）。


### 2. Q10（label/patch 広域 + lr=1e-3）が僅差で最良だが、改善量は誤差範囲

- Q10: test_mae=0.1019、train_mae=0.0716。Q1 との生 t 差は `-0.0022`（paired t-test p=0.067, n.s.）。
- perp_scale=2.0 で法線方向を広く取り込み、patch_t を (-2, 3) に広げた効果は微小。
- `patch_t_min=-2.0` / `patch_t_max=3.0` の組み合わせは EXP012 では未検証領域（EXP012 は `-1.0〜-1.25` × `2.0〜2.25` の格子）。**より広い t 範囲を patch に取り込む余地** はまだあるかもしれない、だが現 CNN のサンプリング解像度 64 では新情報が活きない可能性が高い。

### 3. L4（EXP010 の前ベスト）・E6（EXP011）・A_p10_h064_w064（EXP012）・Q1/Q10（EXP013）は事実上同性能

- 生 t test_mae が 0.102〜0.105 のレンジに収束しており、**現アーキテクチャ × 現データ** での下限に到達した兆候。
- 「ハイパラの組み合わせ最適化」では頭打ち。次の一手は **アーキテクチャ変更 / データ品質改善 / 目的関数の再設計** のいずれか。


## 結論・次の実験への示唆

### 結論

- EXP011 で観測された `lr=1e-3` / `conv5` / `t_weighted_loss α=3` の単体効果は **組み合わせても加算しない**。Q6（本命）は Q1（EXP012 ベースライン）を超えなかった。
- 現アーキテクチャ（custom CNN / conv4〜5 / patch 64×64）の test MAE は **生 t 空間で 0.102〜0.105 に飽和**。L4（EXP010）以降のハイパラ探索（EXP011 / EXP012 / EXP013）は有意な改善を生んでいない。
- 正規化 MAE の見かけ上の変化（Q7/Q8/Q10 の 0.034〜0.038）は `label_t` 範囲の分母効果に過ぎず、**生 t に換算して初めて公平に比較できる**。
- 暫定ベスト条件: **Q10_lr3_label_wide_scale（test_mae=0.1019）**。ただし差は誤差範囲で、実用ベストは Q1_EXP012_baseline（0.1041）でも差し支えない。
