# EXP010: データv2（~6930件）× wide_patch 再検証

## 目的

DB更新（~5700→~6930件）後の新データセットで、EXP006ベスト条件である
H2_wide_patch をそのまま再実行し、データ増加による性能向上を検証する。

**仮説**: データ量が約1.2倍増えることで、wide_patch 構成の汎化性能がさらに向上する。

## 条件

| 条件 | lr | conv層 | flip | use_pq_ratio | 変更点 |
|------|:---:|:---:|:---:|:---:|--------|
| L1_wide_patch | 1e-4 | 3 | ✓ | ✗ | EXP006 H2_wide_patch をデータv2で再実行（ベース） |
| L2_wide_patch_pq | 1e-4 | 3 | ✓ | ✓ | pq_ratio を補助入力に追加 |
| L3_wide_patch_wo_flip | 1e-4 | 3 | ✗ | ✗ | 水平反転 augmentation を除外 |

| L5_wide_patch_wo_flip_deep5 | 1e-4 | **5** | ✗ | ✗ | L3 + conv 層数 5 化 |

## 考察

### 1. データ増加で大幅改善（ユーザー仮説の確認）

EXP006 → EXP010 の性能向上は確認されたが、原因はユーザーの仮説とやや異なる：

- **仮説**: 大きい目のデータが増えたから良くなった
- **実際**: 新規データは確かに大きい目（median 124px）が中心だったが、
  eye_scale 自体は誤差との相関がほぼゼロ（r=+0.015）

**真の改善要因**: より多様な画像（50枚の新規画像）からの訓練データ増加が
モデルの汎化性能を向上させた。eye_scale の大きさより画像の多様性が効いている。

### 2. 誤差の真因は pq_ratio（相対的なアイライン長）

pq_ratio（= PQ距離 / eye_scale）が誤差の最も強い予測因子（r=-0.251）。
**アイラインが目に対して相対的に短いサンプルほど t の予測が難しい。**

これはアーキテクチャ的に本質的な問題：パッチ画像に占めるアイライン情報が少ないと、
どの位置が t=0 でどこが t=1 かの手がかりが弱くなる。

### 3. テストセットが難化したにもかかわらず改善

- EXP006 test: median eye_scale = 70.9 px（比較的大きい目）
- EXP010 test: median eye_scale = 61.3 px（やや小さい目）

EXP010 は難しいテストセットでより良いスコアを出している。
純粋な訓練データ増加によるモデル改善が寄与していると解釈できる。

### 4. t > 1.0 のバイアスが改善

t>1.0（アイライン末端外側）のバイアスが -0.311 → **-0.236** と改善。
広い wide_patch 範囲（patch_t_min=-1.0 / patch_t_max=2.0）が
訓練データ増加と相乗効果を発揮した可能性がある。

### L2（use_pq_ratio）の考察

pq_ratio を補助入力にしても全体 MAE はほぼ変わらず（0.1121 vs 0.1124）。
pq_ratio Q1（最も短いアイライン）の改善も見られなかった（むしろ微悪化）。

pq_ratio は誤差の予測因子ではあるが、補助入力として与えても
「短いアイラインは難しい」という困難自体は解消されない。
t>1.0 のバイアスはわずかに改善（-0.236→-0.226）したが誤差範囲内。

### L3（水平反転なし）の考察

aug_flags から AUG_FLIP（0x40）を除外した結果：

**CV vs Holdout の乖離**:
- CV MAE は 0.05768 → **0.05431**（-5.5%改善）と大幅に向上
- Holdout MAE は 0.05603 → 0.05673（+1.3%悪化）と微悪化
- 相関係数も 0.698 → 0.684 と低下

CV の改善は「CV での各 fold が同じ方向性のデータを見る」効果であり、
flip なしによる過学習（訓練データへの過適合）が生じている可能性がある。

**バイアスパターン**:
- t>1.0 のバイアスは -0.236 → -0.219 とわずかに改善
- t<0.2 のバイアスは +0.449 → +0.465 と悪化

水平反転は左右非対称なアイライン検出においても、データ多様性を増やす
正則化効果として有効に機能している。flip を除くと汎化性能が低下する。

**ただし後述の L4（wo_flip + conv4）と L6（wo_flip + lr=1e-3）では
この劣化を打ち消して L1 を上回れることが判明した。** L3 単独での
flip 除去は不可でも、他のハイパラと組み合わせれば活用可能。

### L4（wo_flip + conv4）の考察

L3 の conv3 のままだと flip 除去で汎化が落ちたが、conv 層を 4 に
深めるとモデル容量が増えて flip なしの分の正則化を学習し直せる。

**指標**:
- CV MAE: 0.05431 → **0.05377**（L3比 -1.0%）
- Holdout (norm): 0.05673 → **0.05544**（L3比 -2.3%、L1比 -0.8%）
- 生t MAE: 0.1137 → **0.1111**（L1の0.1121も上回る）
- 相関係数: 0.684 → **0.711**（全条件中ベスト）

**エッジケースの改善**:
- t < 0.2 のバイアス: +0.465 → **+0.424**（L1の+0.449も下回る、全条件中ベスト）
- t > 1.0 のバイアス: -0.214 → **-0.186**（L1の-0.233を大幅に改善、20%削減）
- 0.8–1.0 のバイアス: -0.071 → **-0.061**（全条件中ベスト）

**L4 は L1 を全指標でわずかに超える新ベスト候補。** エッジケース（t<0.2, t>1.0）
での改善が特に顕著で、wide_patch の広範囲予測能力とモデル容量増加が
相乗効果を生んだと解釈できる。ただし Holdout norm 差 0.00046 は
std（0.002）の範囲内で、統計的有意性は弱い。

### L5（wo_flip + conv5）の考察

conv 層を 5 まで深めるが、L4 から改善しない（むしろ悪化）。

- CV MAE: 0.05377（L4）→ 0.05399（L5、微悪化）
- Holdout (norm): 0.05544（L4）→ 0.05656（L5、+2.0%悪化）
- 相関係数: 0.711（L4）→ 0.684（L5、低下）

**conv4 が最適で、それ以上深めると過学習側に振れる。** データ5264件に対して
conv5 はパラメータ過多で、L4 の汎化バランスが崩れている。

### L6（wo_flip + lr=1e-3）の考察

L3 の lr を 1e-4 → 1e-3 に上げた結果、L4 と並ぶトップクラスに到達。

- CV MAE: 0.05431（L3）→ **0.05426**（ほぼ同等）
- Holdout (norm): 0.05673（L3）→ **0.05540**（L3比 -2.3%、全条件中ベスト）
- 生t MAE: 0.1137 → **0.1110**（L4の0.1111と事実上同値）
- 相関係数: 0.684 → 0.700（L4には届かず）

**高い lr が flip 除去による訓練の偏りを抑える可能性**: 学習率が大きいと
訓練データへの過適合が起きにくく、flip 無しで失われた多様性の一部を
相殺している可能性がある。CV は L3 とほぼ変わらないので、汎化に寄与する
効果は Holdout の方により強く表れている点は注意。

### L7（flip あり + conv4）の考察

L4 との唯一の違いは flip 有無。conv4 単独の効果を切り出すための対照群。

- CV MAE: L4 0.05377 vs L7 0.05634（+4.8%悪化）
- Holdout (norm): L4 0.05544 vs L7 0.05562（ほぼ同等）
- 相関係数: L4 0.711 vs L7 0.703

**conv4 単独（L7）でも L1 より Holdout MAE は微改善（0.05590 → 0.05562）**
するが、CV は L1 より悪化。**conv4 の真価は wo_flip と組み合わせた L4 で発揮される**：
flip 除去によるデータ数実効増加（左右反転分の二重学習を回避）と
モデル容量増加が噛み合う構造になっている。

### L8（wo_flip + lr=1e-3 + conv4、全部盛り）の考察

L4・L6 の良い条件を組み合わせれば最良になるはず、という仮説の検証。

- CV MAE: **0.05428**（L4 0.05377、L6 0.05426）→ L6 と同等、L4 より悪化
- Holdout (norm): **0.05661**（L4 0.05544、L6 0.05540）→ **両者に劣る**
- 生t MAE: 0.1135（L4 0.1111、L6 0.1110 に及ばず）

**組み合わせは単純に足し算にならず、むしろ相殺してしまう。** 高 lr と
深い conv は学習の不安定化を招き、L4 が持っていた低バイアス（t<0.2 +0.424）を
失っている（L8 では +0.454 に戻る）。ハイパラ間の相互作用があり、
「良い設定の組合せ = 最良」は成立しない。

### 生 t MAE で見た実質順位（改善率は小さい点に注意）

L6（0.1110）＞ L4（0.1111）＞ L7（0.1115）＞ L1（0.1121）＞ L2（0.1124）＞ L5・L8（0.113x）＞ L3（0.1137）

L1〜L8 のトップ4（L6, L4, L7, L1）は差が 0.0011 以内で、std（fold 単位で 0.002〜0.003）
と同オーダー。**L4/L6 は新ベスト候補だが、有意差は弱い。** ただし
**L4 は t>1.0 バイアスの顕著な改善**（-0.233 → -0.186）という
定性的な強みがあるので、エッジケース重視ならば採用価値あり。

## 結論

**L4_wide_patch_wo_flip_deep4 が新ベスト候補**（L1 を全指標でわずかに超える）。
ただし Holdout 差は std の範囲内で統計的有意性は弱く、主な成果は
**t>1.0・t<0.2 のエッジケースバイアスの改善**。

- 生t MAE: 0.1111（L1比 -0.9%、EXP006比 **-12.2%**）
- Holdout norm: **0.05544**（L1 0.05590 比 -0.8%）
- 相関係数: **0.711**（全条件中ベスト）
- t>1.0 バイアス: -0.233 → **-0.186**（20% 改善）
- t<0.2 バイアス: +0.449 → **+0.424**（5.6% 改善）

**条件別採否**:

| 条件 | 採否 | 理由 |
|---|:---:|---|
| L2（pq_ratio 補助入力） | ✗ | L1 比で効果なし（+0.0003）|
| L3（flip 除去 単独） | ✗ | CV 改善するが Holdout +1.5% 悪化 |
| **L4（wo_flip + conv4）** | **◎** | **全指標で L1 を上回り、エッジケース大幅改善** |
| L5（wo_flip + conv5） | ✗ | 深さ 5 は過学習方向、L4 比で悪化 |
| L6（wo_flip + lr=1e-3） | △ | Holdout は L4 と同等だが相関はやや劣る |
| L7（flip + conv4） | △ | L4 より劣るが、flip は有効という論点の裏取り |
| L8（全部盛り） | ✗ | L4/L6 の良さが相殺、相互作用で悪化 |

**次の実験方向として推奨**:
- **L4 構成（wo_flip × conv4）をベースに据え直す**: EXP011 以降の起点
- **pq_ratio 低サンプル（Q1, MAE=0.157）への対策**: 損失重み付け or 専用アーキテクチャ
- **さらなるデータ拡充**: 特に多様な画像（eye_scale の大小より画像の多様性が効く）
- **t<0.2 の平均回帰バイアス**（+0.42）解消が最優先課題
- **flip × モデル容量のハイパラ相互作用**を EXP011 で網羅的に検証
