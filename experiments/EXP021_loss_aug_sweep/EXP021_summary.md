# EXP021: 損失関数 sweep（空間 × カーネル 2軸直積）

## 目的・仮説

EXP020 の単一ブランチ 2 系統（生PQ=none / P'Q'=eye_scale）上で損失関数を sweep し、
EXP020 ベスト（dual X1_independent = 生t MAE 0.0854）の更新に資する損失を特定する。

損失を **「空間 × カーネル」** の 2 軸に分解した完全直積で評価:

| 空間＼カーネル | L1 | Huber | Wing |
|---|---|---|---|
| 正規化t | `t_l1` | `t`（現行） | `wing` |
| 目正規化px | `error_ratio` | `error_ratio_huber` | `wing_px` |

- 目正規化px = 残差を `(label_t_max−label_t_min)·pq_ratio` でスケール（pq_ratio = pq_dist/eye_scale）。
- `error_ratio`（px×L1）はユーザ提案 `|t_pred_raw−t_true_raw|·pq_dist/eye_scale`。
- aug は EXP020 baseline(127) 固定で損失効果を分離。
- 系統 base は EXP020 X0_none / X0_eye_scale と同一設定。manifest 流用（data_version=59ae3828）→ EXP020 と直接比較可能。
- k=3, epochs=200, patience=50, seed=42, custom backbone。N_train=10710, N_holdout=7308。

## 考察

1. **カーネル: L1 > Huber > Wing（最重要）。** L1 が Huber を全空間で上回り、eye_scale の t 空間で有意（p=1.6e-5、−2.1%）、px 空間でも両系統で有意。Wing は両系統・両空間で明確に悪化（とくに裾野 t<0 / t≥1.2 を破壊）。

2. **空間効果（pq_ratio 再重み付け）は中立〜有害。** `error_ratio` の核である pq_dist/eye_scale 重みは生t MAE を改善せず、eye_scale で有意に悪化。**しかも error_ratio が最適化するはずの px-norm 指標でも t_l1 に敗北**（0.00923 vs 0.00912）。EXP001 で `normalized_pixel`（px×Huber 系）が素の t に敗れた逆風を再確認。小pq サンプルのダウンweighting が汎化に効かず、per-sample 重みが実効学習率ノイズとして作用した可能性。

3. **Wing の悪化はハイパラ未調整の可能性。** ω=0.1, ε=0.01 固定。t スケールに対し非線形領域が広すぎ小誤差を過剰増幅した恐れ。Wing を結論づけるには ω/ε sweep が別途必要（本実験では非推奨判定）。

4. **t_l1 は裾野も改善。** t<0・t≥1.2 帯で t を上回る（両系統）。secondary 目標にも整合。

## まとめ

- **勝者 = `t_l1`（素の L1/MAE 損失）。両系統・両指標でベスト。**
- ユーザ提案 `error_ratio`（px 再重み付け）は **生t ゲートでも px-norm ゲートでも棄却**。
- Wing は未調整で悪化（ω/ε sweep が前提）。
- 皮肉にも、ユーザが直積の欠落セルとして指摘した **`t_l1`（正規化t × L1）が最良の損失**だった。

## 考察

1. **FLIP は有害。** 両系統で woflip（FLIP off）が baseline を有意に上回る。none: −2.5%（p=5e-4 ***）、eye_scale: −1.5%（p=0.027 *）。EXP010「wo_flip 有利」を再確認。

2. **EBR=0.25 がスイートスポット。** EBR を 0（無効）にすると両系統で顕著に悪化（+0.0061、p<1e-14）。0.15 も悪化傾向（none 有意、eye_scale n.s.）。0.35 以上は裾野改善（特に t≥1.2）と引き換えに中間帯（0.3-1.0）を劣化させ、全体 MAE は悪化。

3. **EBR 大（0.35-0.50）は裾野に効くが中央が崩れる。** ebr050__none は t<0 0.3681（baseline 0.4349 から改善）だが 0.3-0.7 0.0892（baseline 0.0816 から悪化）。トレードオフが顕著で、全体 MAE 最適化には baseline 0.25 がベスト。

4. **両系統で woflip が勝利。** 系統間の交互作用はなく、FLIP off の効果は一貫している。

## Phase 2 結論

- **勝者 = `woflip`（FLIP off, flags=63, EBR=0.25）。** 両系統で有意に改善。
- **ENDPOINT_BLEND_RANGE=0.25（現行値）が最適。**
- `t_l1` + `woflip` の組み合わせが単一ブランチの最良設定。

# Phase 3: dual-branch X1_independent への移植（損失=t_l1, aug=woflip）

## 目的

Phase 1+2 勝者（`t_l1` + `woflip`）を dual-branch X1_independent（EXP020 ベスト構成）へ適用し、EXP020 ベスト 0.0854 の更新可否を確認する。

## 設定

- fusion_mode: independent, rescale_b: eye_scale（EXP020 X1 と同一構成）
- loss_fn: t_l1, aug_flags: 63（FLIP off）, endpoint_blend_range: 0.25
- k=3, epochs=200, patience=50, seed=42

## 結果

| 指標 | Phase 3 | EXP020 X1（旧ベスト） | 差分 |
|------|---------|----------------------|------|
| CV MAE (norm) | 0.02990 | 0.03084 | −3.1% |
| Holdout MAE (norm) | **0.02752** | 0.02848 | −3.4% |
| **Holdout MAE (raw-t)** | **0.0826** | 0.0854 | **−3.4%** |

paired t-test: t=−5.858, **p=4.9e-09 (\*\*\*)**, delta=−0.00288

## 考察

1. **EXP020 ベスト 0.0854 を有意に更新（p=4.9e-09）。** t_l1+woflip の改善効果は dual-branch にも転移した。
2. **全バンドで改善（0.3-0.7 帯を除く）。** 特に t<0（−11.4%）・1.0-1.2（−8.3%）の極端帯で大きく改善。
3. **0.3-0.7 帯のみ微増（+2.7%）。** この帯はデータ数最多（N=2533）かつ既に低 MAE（~0.08）であり、実用上の問題は小さい。

## ベスト設定

## 限界

- 効果量は ~3%。aug は default_rng 無シードで確率的 → run 間変動あり。
- 0.3-0.7 帯で微増（+2.7%）。全体最適化と帯別トレードオフは残存。
- Wing/error_ratio_huber/wing_px のカーネル定数（delta, ω, ε）は固定（未sweep）。
