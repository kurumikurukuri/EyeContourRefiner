# EXP030: データオーグメンテーション発火頻度(aug_prob) sweep

## 目的・仮説

EXP021 Phase2 で「どのオーグメンテーションを有効にするか」（aug_flags のビット on/off）を
sweep し FLIP off（aug_flags=63）が勝者と判明したが、有効化した各オーグメンテーションが
「どのくらいの頻度で発火するか」は一度も検証されていない。BRIGHTNESS/BLUR/COLOR_TEMP/FLIP
は augment() 内で固定確率 0.5 のまま実装されており、この値の妥当性は未検証だった。

本実験では、これら基準確率0.5の4種のみに掛かる倍率 `aug_prob` を新設し
（実効確率 = 0.5 × aug_prob をクランプ）、0.5/1.0/1.5倍（実効確率 0.25/0.5/0.75）で
sweep した。NOISE（常時発火）・GRAYSCALE（基準0.2）・ENDPOINT_BLEND（幾何系）・
perspective_aug（EXP027の軸）は対象外とし、全 config で固定する。

仮説: 発火頻度は augmentation の「強さ」の一種であり、強すぎれば学習を阻害し、
弱すぎれば正則化効果が不足する可能性がある。0.5 が過去実験を通じて暗黙に採用されてきた
値であるため、これを中心に上下対称に振ることで、現在の値が最適解に近いかどうかを確認する。

## 実験設計・条件

- **実験ディレクトリ**: `experiments\EXP030_aug_freq_sweep`
- **config 数**: 3
- **config 一覧**: AF0_baseline, AF1_p0p25, AF2_p0p75
- **評価指標**: cv_mae, holdout_mae(raw t), passrate(std/strict)
- **passrate 閾値**: std=0.01788 (p10), strict=0.01604 (p5)
- **検定方法**: scipy paired t-test（per-sample abs error）
- **テストセット**: EXP029 で採用が決まった `db_replica` 固定 manifest
  （`manifests/manifest_{train,test}.csv` は EXP029 の
  `manifest_{train,test}_db_replica.csv` をそのままコピー、diffゼロで一致確認済み）

**固定条件**: bc32_pw8（base_channel=32, pool_width=8）+ k3_b32（k=3, batch=32）+
aug_flags=63（FLIP off, EXP021 Phase2 勝者）= EXP028 LN0_baseline / EXP029 baseline
相当と同一構成。endpoint_blend_range=0.25、perspective_aug は無効のまま。

**変動軸**: `aug_prob` のみ（BRIGHTNESS/BLUR/COLOR_TEMP/FLIP の基準発火確率0.5に掛かる倍率）。
- AF0_baseline: aug_prob=1.0（実効確率0.5, 現行標準の再現 = anchor）
- AF1_p0p25: aug_prob=0.5（実効確率0.25, 半減）
- AF2_p0p75: aug_prob=1.5（実効確率0.75, 増加）

NOISE（常時発火）・GRAYSCALE（基準0.2）は augment() 内で aug_prob の対象外として固定。

## 考察

- 全体 MAE は AF1_p0p25(0.084425) > AF0_baseline(0.084092) > AF2_p0p75(0.083667) の順で、
  発火頻度を上げるほど単調にわずかに改善する傾向が見える（pass_std も 89.02%→89.20%→89.27%
  と単調増加）が、いずれも AF0_baseline との差は 1% 未満で、後述の paired t-test でも
  ALL レベルでは両方とも n.s.（AF1: p=0.422, AF2: p=0.312）。
- AF0_baseline の pass_std(89.20%)・pass_strict(86.16%) は EXP029 baseline（同一構成・
  同一 manifest, pass_std 89.27%/pass_strict 85.92%）とほぼ一致しており、1 seed 学習の
  run-to-run 分散の範囲内で再現できている。
- 結論として、**aug_prob を 0.5〜1.5倍（実効確率 0.25〜0.75）の範囲で振っても全体成績に
  統計的に有意な差は生じない**。この軸は現状 EXP026 の k/batch と同様に「飽和」している
  可能性がある。ただし後述の通り t帯別には非一様な効果が存在する。

## t帯別結果考察

t帯別に見ると、全体では n.s. だった差が **多数派帯と極端帯で逆方向に相殺し合っている** ことが
分かる。

- **多数派帯（0.3-0.7: n=1684, 0.7-1.0: n=2430、合計で全体の84%）**: AF2_p0p75 は両帯とも
  有意に改善（0.3-0.7: +2.12%, p=0.011*／0.7-1.0: +1.88%, p=0.009**）。AF1_p0p25 も
  0.3-0.7 帯では有意に改善（+1.77%, p=0.025*）。サンプル数が多く典型的な見た目のパッチが
  大半を占めるこの帯域では、発火頻度を上げる方向（AF2）がより一貫して効いている。
- **極端帯（t<0: n=129, 0-0.3: n=219）**: 逆に AF1_p0p25 は t<0 帯で有意に悪化
  （-8.84%, p=0.002**）、AF2_p0p75 も t<0（-5.61%, p=0.040*）・0-0.3（-3.75%, p=0.027*）
  の両方で有意に悪化。t<0 帯は AF1（弱める）・AF2（強める）どちらの方向にずらしても
  baseline(0.5) より悪化しており、単調な「強いほど良い/悪い」ではなく baseline 近辺が
  ローカルに良い可能性がある。ただし n=129〜219 と小サンプルで、EXP028 の議論にもある通り
  極端帯は 1 seed 学習の run-to-run 分散の影響を受けやすく、この非単調性が真の aug_prob
  効果かどうかは慎重に見る必要がある。
- **1.0-1.2 帯（n=351）・t>=1.2 帯（n=87）**: いずれも n.s.（p>0.17）で、明確な傾向は
  確認できなかった。

まとめると、**発火頻度を上げる方向（AF2_p0p75）は多数派帯を有意に改善する一方、
少数派の極端帯（特に t<0）では有意に悪化する** というトレードオフが観測された。
全体 MAE が n.s. なのは、n の大きい多数派帯の改善（合計 n=4114）と n の小さい極端帯の
悪化（合計 n=129〜348）が絶対誤差の大きさで相殺し合った結果と解釈できる。

## ペア比較考察

- **AF1_p0p25 vs AF0_baseline**: ALL n.s.（-0.40%, p=0.422）。帯別では 0.3-0.7 帯のみ
  有意に改善（+1.77%, p=0.025*）、t<0 帯は有意に悪化（-8.84%, p=0.002**）と符号が割れる。
  発火頻度を半減させても大部分の帯（0-0.3, 0.7-1.0, 1.0-1.2, t>=1.2）は n.s. で、
  「半減させても実害はほぼない」が「t<0 帯だけは明確に悪化する」という結果。
- **AF2_p0p75 vs AF0_baseline**: ALL n.s.（+0.51%, p=0.312）だが、5/6帯で有意差が出ており
  AF1 より効果がはっきりしている。多数派帯（0.3-0.7, 0.7-1.0）は有意に改善、極端寄りの
  帯（t<0, 0-0.3）は有意に悪化、中間の 1.0-1.2 と最極端の t>=1.2 のみ n.s.。
  「発火頻度を上げると典型例に強くなる代わりに、少数派の非典型例（t<0 付近）に弱くなる」
  という一貫したトレードオフ構造が最も明瞭に表れた config。
- 両 config とも t<0 帯（n=129 と全体の2.6%のみ）で baseline より悪化する点は共通しており、
  aug_prob=0.5（baseline）が少なくともこの狭い帯に関してはローカルに良い値である可能性を
  示唆する。ただし n=129 は小さく、1 seed のみの学習であるため、この効果が真に aug_prob
  依存かどうかは複数 seed での再検証が望ましい。

## 結論

- **全体 MAE・passrate レベルでは aug_prob（0.5〜1.5倍、実効確率0.25〜0.75）は現行の
  0.5 から統計的に有意な差を生まない。** この範囲では発火頻度は「飽和」している軸であり、
  単独では大きな改善余地はない。
- ただし t帯別には明確なトレードオフがある: **AF2_p0p75（実効確率0.75、発火頻度増）は
  多数派帯（全体の84%を占める 0.3-0.7・0.7-1.0）を有意に改善する一方、少数派の極端帯
  （t<0・0-0.3）を有意に悪化させる。** 全体 passrate（89.27%, AF0比+0.07pt）・全体 MAE
  （0.083667, AF0比+0.51%）はわずかに AF0_baseline を上回っており、3 config 中最良では
  あるが、この差自体は non-significant なので「明確な勝者」として断定はしない。
- **本採用は見送り、現行の aug_prob=1.0（実効確率0.5）を当面維持する。** 多数派帯の改善と
  極端帯の悪化どちらを重視するかはプロダクト要件次第であり、Completion_Criteria.md の
  判定は全体 passrate ベースのため、現時点では変更の正当化根拠が弱い。

## 今後の課題

- 本実験は aug_prob ∈ {0.5, 1.0, 1.5}（実効確率 0.25〜0.75）という baseline 近傍の
  狭い範囲のみを検証した。より極端な値（aug_prob=0（完全無効）や 2.0以上）を含めた
  sweep を行えば、飽和ではなく単調な傾向が現れる可能性がある。
- NOISE・GRAYSCALE の発火確率、および ENDPOINT_BLEND（幾何系augmentation）の頻度は
  本実験の対象外とした。これらは別軸として独立に sweep する価値がある。
- perspective_aug（EXP027）との交互作用は未検証。発火頻度を上げた photometric
  augmentation と幾何 augmentation を併用した場合の効果は別実験で確認する価値がある。
