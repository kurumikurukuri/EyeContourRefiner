# EXP035: PQ ランドマーク回転摂動 augmentation（PQ jitter）

## 目的・仮説

本番の P, Q は FaceMesh の推定値で PQ の向き（角度）の誤差を含むが、学習では再現していない。
R = tP + (1-t)Q を固定したまま、R を中心に P, Q を θ ~ U(±θmax) 回転した入力で学習すれば
（t は不変）、FaceMesh 誤差に頑健になり hold-out MAE も改善する、という仮説を検証する。
1 seed のスクリーニングで、有望なら EXP036 で 3 seed 確認する。

## 実験設計・条件

- **実験ディレクトリ**: `experiments/EXP035_pq_jitter`
- **config 数**: 6
- **config 一覧**: J0_base, J1_weak, J2_strong, J3_xstrong, J4_rot20, J5_rot30
- **評価指標**: cv_mae, holdout_mae(raw t), passrate(std/strict)
- **passrate 閾値**: std=0.01788 (p10), strict=0.01604 (p5)
- **検定方法**: scipy paired t-test（per-sample abs error）

- **変動軸**: 学習時の回転幅 θmax（J0=なし / J1=±5° / J2=±10° / J3=±15° / J4=±20° / J5=±30°）。`aug_flags` は J1〜J5 が 63|0x200=575。
  J3 は J0〜J2 で回転幅に対し単調に改善したため、J4・J5 は J3 でも悪化しないため「悪化に転じる点」を探す目的で、
  それぞれ前の結果を見てから後から追加した（事後追加の探索条件である点に注意。仕様書の当初条件は J0〜J2）。
- **固定条件**: 現行dual標準（EXP033 dual_s42 / EXP034 base と同一構成）、seed=42、k=3、
  EXP034 と同一の db_replica 固定 manifest、`num_workers=0`。
- **頑健性評価**: テストの P, Q を R 中心に ±3°（固定 seed=0）回転した入力で MAE を測り、クリーンからの劣化幅を比較
  （`scr/robustness_exp035.py`）。

## 考察

- hold-out MAE（生 t）は J0=0.08429 → J1=0.08397（−0.38%）→ J2=0.08262（−1.98%）→ J3=0.08153（−3.27%）
  → **J4=0.08114（−3.73%、最良）** → J5=0.08183（−2.92%）。±20° まで単調に低下し、±30° で上昇に転じた。
- **悪化に転じる点**: 全体 MAE の山は ±20° 付近。ただし ±15° / ±20° / ±30° の間の差は全体では有意でない
  （J4 vs J3: +0.47%・p=0.36、J5 vs J3: −0.37%・p=0.54）。±15〜±30° は「ほぼ高原」で、
  ±30° でも J0 より 2.92%（p<0.0001）良く、全体 MAE で J0 を下回る点は見つかっていない。
- **J2〜J5 は判定基準（0.52% 超かつ p<0.05）を満たす**: 改善は J2 1.98% / J3 3.27% / J4 3.73% / J5 2.92%（いずれも p<0.001）。
  J1_weak は 0.38%・p=0.42 で n.s.。
- passrate は J4 が std/strict とも最大（90.02 / 87.16）、次いで J5・J3。J1〜J3 は J0（89.18 / 85.80）より
  高いが差は 0.4〜0.6pt 以内で、MAE ほどきれいな単調性はない。
- cv_mae（val MAE）は J2=0.028881 と J3=0.028880 でほぼ同一だが、hold-out では J3 が 1.3% 低い。
  cv_mae は早期終了の選択に使った val なので、強度の優劣は hold-out で判断する。
- **頑健性指標は差を識別できなかった**（下表）。±3° 回転の劣化幅は J0 でも 0.06% しかなく、
  もともと ±3° 程度の回転には鈍感なため、J1〜J5 との差（p=0.56 / 0.97 / 0.65 / 0.90 / 0.50）も出なかった。

- したがって改善の出どころは「ランドマーク誤差への頑健化」ではなく、クリーン入力での汎化改善
  （回転 augmentation による正則化・データ多様化）である可能性が高い（推測。本実験では切り分けていない）。

## t帯別結果考察

- J1・J2 では改善が多数派帯の 0.3-0.7（J1 +2.1%、J2 +4.5%）と 0-0.3（J2 +3.9%）に集中し、0.7-1.0 と 1.0-1.2 は ±0.3% 以内で
  変化なし、極端帯（t<0、t>=1.2）は符号が揃わず n.s.（t>=1.2 は J1・J2 とも悪化 −3.3〜−3.6%、n=87）だった。
- J3 では様相が変わり、0.3-0.7 は +0.9%（n.s.）に縮んだ一方、0.7-1.0（+3.0%）・1.0-1.2（+7.2%）・t<0（+6.7%）・
  t>=1.2（+8.2%）で改善し、全帯で J0 を上回った（符号は全帯で正）。
- J4・J5 では 0.3-0.7 の改善が拡大（J3 +0.9% → J4 +5.4% → J5 +6.0%、J5 vs J3 は p<0.001）する一方、
  0-0.3 は J3 +4.0% → J4 −0.3% → J5 −6.2%（J5 vs J0 p=0.018、J5 vs J3 −10.6% p<0.001）と回転幅が大きいほど悪化した。
  1.0-1.2 は J3 +7.2% → J4 +5.5% → J5 +3.6%、t>=1.2 は +8.2% → +5.9% → +2.0% と縮み、極端帯は J3 が最良。
- 回転幅を変えると改善の出る帯が入れ替わっており、J1〜J3 の間では帯別の傾向は再現しなかった。
  J3→J5 では 0.3-0.7 の増加と 0-0.3 の減少が回転幅に対し単調だが、n（219）が小さい帯を含み、
  seed ノイズ幅との比較もできていないため、確定的な所見としては扱わない。
- ただし [EXP033](../EXP033_seed_variance/EXP033_summary.md) で seed ノイズが t<0 で ±10%、0.3-0.7・1.0-1.2 で ±4% と分かっており、
  **帯別の差は採用根拠にしない**（0.3-0.7 の +4.5% もノイズ幅に近い）。ここでは参考所見に留める。
  J3 の極端帯の改善（t<0 +6.7%、t>=1.2 +8.2%）もノイズ幅（±10%）の内側にあり、n が小さい（129 / 87）ため、
  「極端 t にも効く」とは現時点では言えない。

## ペア比較考察

- J1_weak: 全体は n.s.（p=0.42）。0.3-0.7 のみ p=0.007 だが、帯別は採用根拠にしないため単独では解釈しない。
- J2_strong: 全体 p=0.00012 で有意。0.3-0.7（p<0.001）と 0-0.3（p=0.038）が有意。
  seed 間ばらつきを考えると、有意性より「全体改善が 0.52% を大きく超えた」ことが判断材料になる（約 3.8 倍）。
- J3_xstrong: 全体 +3.27%・p<1e-6。有意な帯は 0.7-1.0（p=0.0003）、1.0-1.2（p=0.001）、t<0・0-0.3・t>=1.2（p<0.05）で、
  0.3-0.7 のみ n.s.。J2 とは有意になる帯が異なる。
- 1 seed 同士の比較のため、J2・J3 の改善がこの seed 固有でないかは EXP036 で確認が必要。
- J4_rot20: 全体 +3.73%・p<1e-6（最良）。J3 との差は +0.47%・p=0.36 で n.s.。有意な帯は 0.3-0.7（p<0.001）、
  0.7-1.0（p<0.001）、1.0-1.2（p=0.012）。
- J5_rot30: 全体 +2.92%・p=0.000038。J3 との差は −0.37%・p=0.54 で n.s.。0-0.3 では J0 より悪化（p=0.018）。
- J3〜J5 は互いに全体では区別できず、「±15〜±30° は同程度の高原」と読むのが妥当。J4 が最良なのは 1 seed のゆらぎの範囲内の可能性が高い。
- J3〜J5 は J0〜J2 の結果を見てから追加した条件で、6 条件のうち最良を選ぶ形になる。選択バイアスの分だけ
  最良条件の改善幅は割り引いて見る必要があり、これも EXP036 の別 seed で確認する。

## 結論

- **J2〜J5（±10°〜±30°）は EXP033 の判定基準（全体改善 0.52% 超かつ p<0.05）を満たした**
  （1.98% / 3.27% / 3.73% / 2.92%）。EXP036 で 3 seed 確認に進む。
- 全体 MAE の最適幅は ±20° 付近（J4 が最良）だが、±15〜±30° の間に有意差はなく高原になっている。
  ±30° で全体 MAE は上昇に転じたが J3・J4 との差は n.s. で、J0 を下回る点は ±30° までに見つかっていない。
  ±30° では 0-0.3 帯が明確に悪化しはじめている（J0 比 −6.2%）。
- EXP036 の候補は J3（±15°）または J4（±20°）。帯別の副作用（0-0.3 の悪化）が出始める前の ±15° を主候補とするか、
  全体最良の ±20° とするかは、3 seed の結果でそろって判断する。
- 頑健性指標では J1〜J3 とも J0 と差が出ず、「頑健性のみで採用を検討する」ケースには当たらない。
- 現時点では採用確定ではなく、1 seed のスクリーニング結果として「有望」止まり。
- J4 の pass_std 90.02% は努力目標 90% を 1 点（+0.02pt）だけ上回ったが、seed SD（0.22pt）の範囲内のため、次実験で詳細を調査する。

## 今後の課題

- **EXP036**: J0 と J3（±15°）・J4（±20°）を 3 seed で比較し、改善が seed ノイズを超えるか、
  事後追加・最良選択のバイアスを割り引いても残るか、J3 と J4 のどちらが安定して良いかを確認する。
  あわせて seed 平均の pass_std が努力目標 90% を超えるかを確認する。
- **強度の探索**: ±30° で全体 MAE が上昇に転じたため、これ以上の幅（±45° など）の探索は優先度が低い。
  代わりに 0-0.3 帯の悪化の原因（大きな回転でこの帯のラベルとパッチの対応が崩れるのか、n が小さいことによるノイズか）を
  seed を増やして確認する。
- **回転幅の分布**: 一様分布 U(±θmax) ではなく、正規分布や prob<1 で小さな回転の比率を増やす案も、
  0-0.3 の悪化を抑えつつ ±20° 級の効果を得る手段として検討できる。
- **頑健性指標の見直し**: ±3° では J0 すら劣化が 0.06% で識別力がない。評価回転幅を ±10° 程度に広げれば差が出るか確認する
  （学習時の摂動幅と同程度なので、学習時分布内の評価になる点に注意）。
