# EXP005 考察まとめ: midダウンサンプル & t外れ値フィルタ sweep

## 実験概要

**目的**: EXP004の分析から判明したmid帯の過剰代表（edge_low 3.1% / mid 71.9% / edge_high 25.0%）を
解消するため、2つのデータ戦略を検証する。

1. **Fシリーズ**: mid帯（0.2≤t≤0.8）をランダムダウンサンプリングしてエッジ帯の学習露出を増やす
2. **Gシリーズ**: t<0 / t>1 の外れ値フィルタ × midダウンサンプルの2×2×2設計

ベース設定: EXP002 sig_tloss（CV=0.0643 / Holdout=0.0642 ※正規化tスケール）

> **スケール注釈**: experiment.json の CV/Holdout MAE は正規化tスケール（patch range 2.0 で除算）。
> 生tスケール = json MAE × 2.0。ピクセル換算 = 生tスケール × patch_h (64px)。

## 考察

### 1. midダウンサンプルは edge_high の平均予測値を上げるが相関を改善しない

midを削減すると edge_high の `t_pred_mean` は上昇する（G1:0.737 → F3:0.769）が、
**相関係数は全条件でほぼゼロ**（r≈-0.06〜+0.004）。

→ モデルは edge_high 区域でサンプルごとの t の大小を識別できておらず、
　単に平均予測値が上昇しているだけ。MAEが改善しているように見えても実質的な識別力の向上ではない。

### 2. midダウンサンプルは mid 精度を犠牲にしてトータルを悪化させる

| 条件 | mid MAE | edge_high MAE | 全体 MAE |
|------|---------|---------------|---------|
| G1_base | 0.082 | 0.151 | 0.1316 |
| F1_mid1500 | 0.086（↑）| 0.140（↓）| 0.1312（≈）|
| F3_mid700 | 0.102（↑）| 0.125（↓）| 0.1394（↑）|

mid=700 以下まで削減すると mid 精度劣化がトレードオフを超え、全体 MAE は悪化。
F1(mid=1500) が唯一 G1 に拮抗するが、EXP002 ベースラインには届かない。

### 3. t<0, t>1 除外フィルタは CV を改善するが holdout を悪化させる

G4（t<0 & t>1 除外）の CV MAE は 0.055 と全条件最良だが、生t holdout MAE は 0.1335 で G1(0.1316) より悪化。

- フィルタで除外した条件（t<0, t>1）をテスト時にも評価するため予測が悪化
- edge_high（0.8<t≤1）の MAE も G1:0.151 → G4:0.169 に悪化
- **CV は「簡単なサンプルだけ」の指標になっており、フィルタ条件では CV/holdout 乖離が大きく CV は信頼できない**

### 4. t<0, t>1 は全モデルで完全な平均回帰（sigmoid 制約による根本限界）

- t<0（平均−0.257）: 全条件で t_pred≈0.51（MAE≈0.76）→ 完全な平均回帰
- t>1（平均+1.150）: 全条件で t_pred≈0.67〜0.73（MAE≈0.42〜0.48）→ 強い平均回帰

sigmoid 出力は [0,1] に制約されるため、範囲外ターゲットは原理的に予測不可能。
この holdout n=44（全体 6.5%）のサンプルが生t MAE を約 0.04 押し上げている。

### 5. EXP002 を超えられない原因

EXP002（生t換算 0.1284, 7.6px）に対し、本実験の全条件が 0.131〜0.139 と劣る。
EXP002 と本実験で使用データ量・テストセットが異なる可能性があるため直接比較は慎重に行うべきだが、
少なくとも「midダウンサンプルでエッジを改善する」戦略は有効でないことが示された。

## 結論

| 検証項目 | 結論 |
|----------|------|
| midダウンサンプル | edge_high の MAE は改善するが相関はゼロのまま。mid 精度の劣化でトータルは悪化 |
| t<0, t>1 フィルタ | CV が改善するが holdout は悪化。フィルタ対象サンプルの予測が悪化するため非推奨 |
| エッジケース改善 | 達成できず。midを削っても edge_high の識別力（r≈0）は改善しない |
| 全体ベスト | F1_mid1500（Holdout norm 0.0656 / 生t 0.1312 / 8.4px）だが EXP002 に届かず |

**次実験への示唆:**

1. **sigmoid 制約の廃止（再検討）**: EXP004 では全体 MAE が悪化したが、
   t<0 / t>1 サンプルへの予測を改善するには出力を非制約にするか、ラベルをクリップ(0,1)する必要がある

2. **edge_high 区域の識別力向上が本質的課題**: r≈0 を改善するには
   - edge_high 帯に高い重みを与えた損失関数（例: t に応じた focal regression）
   - edge_high 専用モデル・ヘッドの分岐
   - より多くのアノテーションデータ（edge_high の絶対量不足）

3. **CVとholdout MAEの乖離への注意**: フィルタ戦略を使う場合、フィルタ対象サンプルを除いた CV は
   実際の汎化性能を反映しない。評価指標は常に全テストセット（フィルタなし）で統一すべき
