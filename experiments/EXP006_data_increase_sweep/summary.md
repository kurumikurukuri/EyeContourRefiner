**テーマ**: データ増加(1.5x) × 最良構成の組み合わせ最適化 sweep  
**データ**: train=4718件 / holdout=1022件  
**実施日**: 2026-04-12〜13

## 実験設計

データを約3150件 → 4718件（約1.5倍増）した環境で、過去に「データ不足で効果なし」と判断された設定を再検証するsweep。

| 条件 | 変更点 |
|------|--------|
| H1_baseline | EXP002 sig_tloss をそのまま再実行（基準線） |
| H2_wide_patch | H1 + wide patch range（EXP003ベスト構成との組み合わせ） |
| H3_deep | H1 + 4層Conv（EXP001では過学習、データ増で有効化を期待） |
| H4_sampler | H1 + t_weighted_sampler α=3.0（EXP002では逆効果、データ増で有効化を期待） |
| H5_wide_patch_short | H2 の epochs=100 短縮版 |
| H6_wide_patch_w | H5 + patch_w=192（幅拡大） |
| H7_wide_patch_scale | H5 と実質同一構成（再現性確認） |
| H8_wide_patch_w_scale | H6 + patch_perp_scale=2.0 |

## 主要な発見

### 1. H2_wide_patch が明確にベスト
`patch_t_min=-1.0 / patch_t_max=2.0 + label_t_min=-0.5 / label_t_max=1.5` の組み合わせが最良。

- H1比で Holdout MAE **-4.4%** 改善（0.06622→0.06332）
- CV-Holdout gap が最小（0.00691）＝汎化性が最も高い
- 生t換算 0.1266 は EXP003 ベスト (0.1268) と同水準であり、新データでも追認された

**解釈**: wide range によりラベル t≈0 付近（線端）や t>1 付近（線外側）のサンプルが学習に取り込まれ、モデルが境界付近での外挿を学習できていると推測。

### 2. epochs=200 は必須（100 では不十分）
H2 (200ep: 0.06332) vs H5 (100ep: 0.06480) で生t換算 +0.030 の差。patience=50 で早期停止があっても 200ep はフル活用されている。

### 3. 4層Conv（H3）はほぼ効果なし
CV は改善するがホールドアウトでの改善は限定的（0.06527 vs H1=0.06622）。容量過剰のアーキテクチャに対してはデータ 4718 件でもまだ足りない可能性がある。

### 4. t_weighted_sampler は依然逆効果（H4）
EXP002 に引き続きデータ増加後も最悪の結果（holdout=0.06653、gap=0.00864）。t=0 付近（少数クラス）に過剰集中することで中間域の汎化が損なわれていると考えられる。

### 5. patch_w 拡大（192px）は効果なし
H5 (w=128: 0.06480) vs H6 (w=192: 0.06535) で悪化。H8 で perp_scale=2.0 と組み合わせると 0.06501 にやや改善するが best (H2) には遠い。アイライン領域に対して w=128（H×2の縦長パッチ）が既に適切なアスペクト比である示唆。

## 次実験への示唆

- wide patch range はデータ規模に関わらず安定して有効 → 以後の標準設定にすべき
- epochs=200 は必要。さらに 300ep に延ばすと改善するか検証価値あり
- 4層Conv を有効にするにはまだデータが足りない可能性（さらなるデータ増加が必要）
- patch 幅方向の拡大よりも高さ方向（patch_h=96 等）を試す価値があるかもしれない
- t_weighted_sampler はこのタスク構造では根本的に相性が悪い可能性が高く、今後の検討対象から外してよい
