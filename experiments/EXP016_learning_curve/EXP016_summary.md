# EXP016: 学習曲線実験（データ量 vs Test MAE）

## 目的・仮説

- **目的**: 訓練データ量を段階的に減らしたとき holdout / test MAE がどう変化するかを測定し、
  目標 MAE の達成に必要なデータ量の概算を得る。
- **対象範囲**: S08（8,107 行）〜 S12（12,880 行・全量）の 5 条件。
- **仮説**: データが多いほど MAE は単調減少し、その傾きから必要データ量を外挿できる。

## 実験設計・条件

- **ベース設定（EXP015 までを引き継ぎ）**: backbone=custom / loss=t / use_sigmoid=true / use_batchnorm=true /
  num_conv_layers=4 / dropout=0.3 / lr=1e-3 / wd=1e-4 / epochs=200 / batch=32 / k=3 / patience=50 / seed=42 /
  aug_flags=127 / patch_t_min=-2.0 / patch_t_max=3.0 / patch_perp_scale=2.0 / patch_h=64 / patch_w=64 /
  label_t_min=-1 / label_t_max=2
- **k=5→3 に変更**: 従来実験（k=5）との CV 値の直接比較はできない。概算が目的のため k=3 とした。
- **manifest**: 本 EXP 専用に DB から再エクスポート（`scripts/split_holdout.py --exp 016`）。
  訓練セットは 12,880 行、holdout は 3,080 行。
- **サブサンプリング**: YAML の `max_train_samples` で指定し、seed=42 固定のランダム抽出で訓練データを制限。

### 条件一覧

| 条件 | max_train_samples | 使用訓練行数 |
|------|------------------:|------------:|
| S08 | 8,107 | 8,107 |
| S09 | 9,087 | 9,087 |
| S10 | 10,067 | 10,067 |

S08→S11 は各 +980 行、S11→S12 のみ +1,833 行（全量に到達するため）。

## 結果

### 評価指標

- `cv_mae` / `holdout_mae`: **正規化 t 空間**（label 範囲 3.0 で除算）の MAE。
- `train_mae` / `test_mae`: 推論スクリプトによる **生 t 空間** の MAE。
- 換算: holdout_mae × 3.0 ≒ test_mae（S12: 0.030191 × 3 = 0.0906 ≈ 0.0909）。

### 定量評価

| 条件 | n_train | CV MAE (norm) | Holdout MAE (norm) | Test MAE (生t) | Train MAE (生t) |
|------|--------:|--------------:|-------------------:|---------------:|----------------:|
| S08 | 8,107 | 0.032679 | 0.030539 | 0.091904 | 0.078360 |
| S09 | 9,087 | 0.032425 | 0.030872 | 0.092901 | 0.076634 |
| S10 | 10,067 | 0.032559 | 0.030465 | 0.091681 | 0.073958 |
| S11 | 11,047 | 0.032129 | 0.030367 | 0.091386 | 0.069927 |
| S12 | 12,880 | 0.031987 | **0.030191** | **0.090859** | 0.066860 |

### 改善効率

| 区間 | n_train 増分 | Test MAE 変化（生t） | 改善/1,000 行（生t） |
|------|------------:|--------------------:|--------------------:|
| S08→S10 | +1,960 | −0.000223 | 0.000114 |
| S08→S12 | +4,773 | −0.001045 | 0.000219 |

## 考察

### 1. 学習曲線はほぼ平坦

holdout_mae は全条件で 0.030191〜0.030872（幅 0.0007）に収まる。訓練データを 37% 削減（12,880→8,107 行）しても
test MAE の悪化は 0.0909→0.0919（約 1.1%）にとどまる。現在の 8,000〜13,000 行の範囲では、
精度のボトルネックはデータ量よりモデル容量・アーキテクチャ側にある可能性が高い。

### 2. S09 の非単調性

S09 の holdout_mae（0.030872）は S08（0.030539）より悪い。fold 間の CV MAE のばらつき
（各条件で最大 0.002 程度）が条件間の差より大きく、k=3・1 seed の統計ノイズと解釈する。
その他の条件（S08→S10→S11→S12）は概ね単調に改善している。

### 3. train_mae のみ明確に低下

train_mae は 0.0784（S08）→ 0.0669（S12）と単調に低下する一方、test_mae の変化は 0.001 程度にすぎない。
データ増加は訓練データへの適合を高めるが、汎化性能にはほとんど寄与していない。

### 4. 目標 MAE に必要なデータ量の試算

S08→S12 の傾き（0.000219 / 1,000 行）で test_mae を線形外挿した値（現在 0.0909 から）:

| 目標 test_mae | 必要な改善 | 必要追加行数（線形外挿） |
|--------------|----------:|-------------------------:|
| 0.090 | −0.0009 | 約 4,000 行 |
| 0.085 | −0.0059 | 約 27,000 行 |

飽和が進むため実際の効率はこれより低下し、上記は楽観的な下限値である。
データ増加よりアーキテクチャ改善・特徴量・データ品質向上を優先すべき。

### 5. 最低限必要なデータ量

- 8,107 行でも test_mae 0.0919 と、全量（0.0909）との差は約 1%。
- 今回の範囲（8,000〜13,000 行）は飽和域で、精度面の下限は 8,000 行以下にある可能性がある。
  下限を特定するには 1,000〜5,000 行の追加測定が必要。

## まとめ

- 訓練データ 8,107〜12,880 行で学習曲線はほぼ水平（test_mae の変化 ≈ 0.001）。
- 現アーキテクチャではデータ追加よりモデル側の改善が有効と示唆される。
- 注釈コスト削減の観点からは、8,000 行程度まで絞っても精度劣化はごく小さい。
