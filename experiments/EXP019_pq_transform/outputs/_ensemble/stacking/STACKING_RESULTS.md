# EXP019 予測値スタッキング

> 複数座標系モデルの予測値を特徴量としてメタ学習器（Ridge / LightGBM / XGBoost / MLP）を訓練。
> N_train=13665, N_test=3430, 5-Fold CV（画像単位 GroupKFold）。

## 入力特徴量（22 次元）

| 種別 | 特徴量 | 次元 |
|------|--------|------|
| 予測値 | X0, X1, X2, X3 の pred_t_raw | 4 |
| 幾何 | pq_dist, pq_ratio, pq_angle (sin/cos), position_polar (sin/cos) | 6 |
| 顔向き | face_yaw/pitch/roll (sin/cos) | 6 |
| 目形状 | eye_scale, norm_eye_scale, lap_var, eye_h_asymmetry | 4 |
| 画像メタ | face_index | 1 |
| 定数 | bias | 1 |

## Ridge の係数（最適ブレンド比率）

```
t_pred = 0.486*X0 + 0.455*X1 + 0.004*X2 + 0.103*X3 + 他19特徴量の微調整
```

- X0 と X1 が主要（合計 0.94）、X2 はほぼ無視（0.004）
- ゲート（run_007）が X1=0.431 を最大重みとしたのと整合。X1 の脱相関効果を Ridge も自動発見


## 結論

- **予測値スタッキング（XGB/LGB）は単純平均を統計的に超えなかった**（paired t-test p>0.83、全体差 −0.1%）。Win/Loss も 1682/1748 とほぼコイン投げ。
- スタッキングがゲートと同様、単純平均を改善できない理由は、4 座標系の予測値がほとんどのサンプルで冗長であり、アンサンブル可能な情報は単純平均で既に取り出せているため。
- Ridge 係数がゲートと一致して X1 の脱相関を発見した点は示唆的だが、スタッキングでもその知見を全体 MAE 改善に結びつけられなかった。
